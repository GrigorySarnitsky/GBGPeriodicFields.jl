GBGPeriodicFields.jl

GBGPeriodicFields.jl is a package for representing, transforming, and manipulating scalar, vector, and tensor fields on three-dimensional rectangular periodic domains. The tensors are Cartesian — components on one fixed right-handed orthonormal frame, with no curvilinear coordinates or metric machinery — so this is an applied field toolkit rather than a general differential-geometry package.

The package is aimed primarily at fluid-dynamics and turbulence simulations. Fields are physical objects, while physical-space and nonredundant spectral representations are storage and manipulation choices. The implementation is designed for both CPU and GPU array backends, with HDF5 field persistence, and includes an unstructured point layer: evaluating fields at off-grid positions (interpolation) and depositing per-point quantities back onto the grid (anterpolation) — the field layer for Lagrangian-particle methods.

This package is not intended to be a ready-to-use DNS solver; rather, it is a toolkit for building fluid-dynamics and general field solvers.

GBGHomogeneousTurbulence.jl is such a solver, and the package's primary consumer: a pseudospectral direct numerical simulation of homogeneous isotropic turbulence built on these periodic fields. Its documentation shows this package in earnest — driving a complete solver, not a worked example.

The GBG part in the name GBGPeriodicFields.jl comes from the city of Göteborg (Gothenburg, Sweden), where the primary development took place.

A few words of vocabulary, used throughout the docs. A field — and its off-grid point-values — is a section: one fiber value (a scalar, a vector, or a second-order tensor) attached to every point of a base (the structured grid, or an unstructured set of points). The operations group as: pointwise algebra within the fiber; differential operators, applied as spectral multipliers; periodic convolution with a kernel; reductions against the base's own measure (a grid cell's volume, a point's count of one), giving a number or a radial profile; and the grid↔point transfer. Each group is catalogued under Main components below. Why they are grouped that way is the Architecture page; you do not need it to use the package.

Installation

This is an unregistered package, so it is not listed in the General Julia registry. To install it, run:

]add https://github.com/GrigorySarnitsky/GBGPeriodicFields.jl

or

using Pkg

Pkg.add(url="https://github.com/GrigorySarnitsky/GBGPeriodicFields.jl")

Then you can use it as usual:

using GBGPeriodicFields

New here? Start with the Getting started tour — a short, runnable walkthrough of grids, fields, representations, operators, reductions, and the point transfer. For a full solver, the Examples page walks through a complete forced-HIT pseudospectral DNS built on the package — the performance-first, allocation-free pattern, with results.

Main components

  • FiberSections: the base-agnostic foundation — the Cartesian fiber types (FiberVector, FiberTensor2/3/4) naming the value at one base point, the AbstractFiberSection supertype fields and point-values share, and the threading primitive and code generators both reuse.
  • Fields: the core types — grids, fields in their physical and spectral representations, and the to_spectral/to_physical transforms between them. It also holds what the other modules build on: similar_field and the allocating constructors, broadcasting, HDF5 persistence, the spectral-kernel supertype, adapt/adapt! for moving a field, its wavenumber multipliers, kernels or FFT plans between host and device, and the check and projector for a real field's spectrum, reality_residual and reality_projection!.
  • FieldAlgebra: fiberwise operations on fields — vector-space operations, scalar actions, vector and tensor products, contractions, pointwise norms, and tensor decompositions, plus map!/map for any other fiber map.
  • DifferentialOperators: differential operators applied as spectral multipliers — gradient, divergence, curl, the inverse curl, the one-pass symmetric gradient, Laplacian, inverse Laplacian, and Helmholtz projection.
  • Convolution: periodic convolution of a field with a kernel, in spectral representation — convolve/convolve! (infix ⋆) apply it as the coefficientwise product of the transforms. A kernel is not a field, and is stored per mode, per axis, by wavenumber magnitude, or as a product; spectral_cutoff/spectral_band, tophat_window, assignment_window, translation_kernel and radial_kernel build them, and exponential_convolve applies an exponential radial kernel without building one.
  • Points: the unstructured base — the Point, PointSet and point-value types, their fiberwise algebra mirroring the field operations in physical representation, the motion pair displace!/wrap!, and HDF5 persistence.
  • Interpolation: the grid↔point transfer — interpolate (gather $W$) and anterpolate (scatter $W^\top$), an adjoint pair, exactly L²-adjoint once rescaled by $N/M$, grid points over points. The scheme is chosen: local physical-domain splines, the exact spectral DirectDFT, or the fast NUFFT. All run on CPU, CUDA and AMDGPU, and a scheme saves to HDF5.
  • Reductions: the L²/measure structure — reductions that integrate the base away against its measure, over fields and point-values alike: the extensive integral, the normalized inner/l2norm/lpnorm, the moments mean/std/var/cov, maximum/minimum/extrema, and the spectral-only, multiplier-weighted weighted_inner. Several also act on a field in spectral representation, with no transform. The radial pair radial_spectrum and radial_correlation resolve the inner product over wavenumber or separation shells.
