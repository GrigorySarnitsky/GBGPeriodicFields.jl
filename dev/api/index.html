API overview

The package is an umbrella module (GBGPeriodicFields) that re-exports a set of submodules. The include order reflects the dependency layering: FiberSections → Fields → FieldAlgebra → DifferentialOperators → Convolution → Points → Interpolation → Reductions.

What each module is for is summarised on the Home page; the pages below are its reference.
