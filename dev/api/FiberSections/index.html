FiberSections

GBGPeriodicFields.FiberSections — Module
FiberSections

Base-agnostic core of the package's fiber-bundle model.

A field (a section over a Grid3D) and a collection of off-grid point-values (a section over a PointSet) are both sections of a tensor bundle over a base (docs/ARCHITECTURE.md §2). This module owns the part of the design that does not depend on the base: the AbstractFiberSection supertype, the CPU-threading / fused-assignment primitive _assign!, and the vertical-algebra code generators (the per-component formula and kernel-body builders) — written once here so that one set of generated kernels serves both field and point-value sections.

The base-specific halves live elsewhere: the concrete types, the section-interface accessors (field_data, _vector_component_data, _tensor2_component_data), fiber_shape, and the broadcast styles are in Fields (grid) and Points (point set), each extending the accessors for its own types; FieldAlgebra and Points stamp the method tables from the builders here.

source

The FiberSections module is the base-agnostic core of the package's fiber-bundle model (docs/ARCHITECTURE.md §2): the AbstractFiberSection supertype shared by fields (sections over a Grid3D) and point-values (sections over a PointSet), the CPU-threading / fused-assignment primitive _assign!, and the vertical-algebra code generators (per-component formula and kernel-body builders) reused verbatim by both FieldAlgebra and Points, so each fiberwise formula is written exactly once.

Public API

GBGPeriodicFields.FiberSections.AbstractFiberSection — Type
AbstractFiberSection{T, R}

Supertype of every section of the package's tensor bundle: fields (sections over a Grid3D, in physical-space or spectral representation) and point-values (sections over a PointSet).

Here T<:AbstractFloat is the real scalar type and R the tensor order (0 scalar, 1 vector, 2 second-order tensor, and so on). The fiberwise algebra is rooted at this supertype because it is base-independent — the same operation on the same fiber type regardless of whether the base is a structured grid or an unstructured point set (docs/ARCHITECTURE.md §2).

GBGPeriodicFields.FiberSections.with_threading — Method
with_threading(f; enabled = true)

Run f() with the CPU-threading decision forced to enabled (true/false, or nothing for the automatic nthreads()-following policy). The override is dynamically scoped and task-local: it affects only f() and is restored afterwards, including on exceptions. Use enabled = false around a region that already parallelizes at a higher level, to avoid oversubscription.

GBGPeriodicFields.FiberSections._SERIAL_CUTOFF — Constant
_SERIAL_CUTOFF

Element count below which an assignment runs serially regardless of thread count: threading overhead is not worth it for small arrays, and this exempts the one-element zero-mode views. Read in the assignment hot path; set with set_threading_cutoff!.

GBGPeriodicFields.FiberSections._assign! — Method
_assign!(destination, broadcasted)

Materialize the lazy broadcasted expression into destination, threaded over chunks on the CPU when _use_threads allows. The generic method is the standard fused Broadcast.materialize! — the safe polarity that keeps GPU arrays and unknown array wrappers on their normal broadcast path (no scalar indexing, honouring invariant 6). Only dense Arrays and Array-backed SubArrays take the threaded path.

source
GBGPeriodicFields.FiberSections._assign_threaded! — Method
_assign_threaded!(destination, broadcasted)

Thread a fused broadcast assignment over contiguous chunks of destination's linear index range. Each task converts its linear indices to Cartesian ones and writes the corresponding broadcast elements, so fusion is preserved (one Broadcasted tree, no temporaries) and the result is bitwise-identical to serial (each index is written by exactly one task). Cartesian indexing of the Broadcasted works on every supported Julia version and correctly remaps singleton operand axes — linear indexing of a multidimensional Broadcasted is only supported on Julia ≥ 1.12. Falls back to serial when the axes do not match (defensive; the field kernels always match).

GBGPeriodicFields.FiberSections._to_broadcasted — Method
_to_broadcasted(expr)

Codegen helper operating on expressions: rewrite a dotted expression — infix dotted operators (a .* b .+ c) and broadcast calls (f.(x)) — into the equivalent lazy Base.Broadcast.broadcasted(...) tree, recursing into operands and leaving non-broadcast subexpressions untouched. Lets generated and hand-written kernels route a fused assignment through _assign! without materializing intermediates (fusion is preserved).

GBGPeriodicFields.FiberSections._vector_kernel_body — Method
_vector_kernel_body(formula; alpha_beta::Bool)

Build the body of a vector-valued kernel: destination_i .= formula(i) for i in 1:3, where formula(i) is the per-component expression. With alpha_beta = true, emit the five-argument destination = α * formula + β * destination form, branching on iszero(β_value) so the pure-overwrite path stays allocation-free. The body ends in return destination and is spliced into a function binding destination (and, when alpha_beta, α_value/β_value).

GBGPeriodicFields.FiberSections.section_scalar_type — Method
section_scalar_type(section::AbstractFiberSection)

Return the real scalar type T of any section. Defined once on AbstractFiberSection{T}, so it gives the real T for fields (including spectral fields, whose data is Complex{T}) and for point-values alike — letting the shared sym/skew/dev kernels obtain T without dispatching on the concrete base.

GBGPeriodicFields.FiberSections.@_assign! — Macro
@_assign!(destination .= rhs)

Threaded replacement for a fused broadcast assignment: rewrite rhs to a lazy broadcast tree (via _to_broadcasted) and assign it through _assign!, so the write threads on the CPU. Use in hand-written kernels in place of .=. (_assign! must be in scope at the call site.)
