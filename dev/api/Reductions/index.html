Reductions

GBGPeriodicFields.Reductions — Module
Reductions

The L² / measure structure on sections — the third operation family, alongside the fiberwise algebra and the differential operators. Periodic convolution and the grid↔point transfer belong to this same family, as two further roles of the one integration structure. A reduction integrates a section over its base against the measure the base carries — the extensive one for integral, its total-mass-one normalization for the intensive reductions: a Grid3D uses its uniform quadrature (the cell volume), and a PointSet uses its counting measure (unit weight per point, forced because a PointSet is grid-free). One set of formulas serves both fields and point-values, dispatched on AbstractFiberSection.

The measure reductions act on fields in physical representation and point-values — representation-free, physical-space quantities. Several also act on fields in spectral representation, returning the identical physical value with no inverse transform: inner/l2norm by Parseval's theorem, integral/mean from the zero (DC) Fourier mode, and the scalar-only std/var from Parseval. The remaining reductions (lpnorm, cov, maximum/minimum/extrema) stay physical-only.

The parts are, each linking to the home where its formula lives.

The moments extend `Statistics`; the order statistics extend `Base`

mean, std, var and cov extend Statistics rather than being owned here, and maximum, minimum and extrema extend Base. Either way they are used exactly as their standard-library counterparts are, and using GBGPeriodicFields alone puts all of them in scope: the umbrella re-exports the four Statistics generics, as it does dot and norm from LinearAlgebra, so a caller need not know which standard library a reduction's verb lives in.

  • integral — the extensive integral, the one quantity that scales with the base measure.
  • mean — the intensive, fiber-preserving arithmetic average over the $N$ grid cells or the $M$ points (it extends Statistics; the mean of a vector field is a FiberVector).
  • std, var, cov — the base moments (extending Statistics, corrected = true by default). The std and var reductions are scalar-only: the sample standard deviation and variance are unambiguous only for a scalar section. The coordinate-free second moment of a vector field is the covariance tensor cov $\equiv R$ with entries $R_{ij} = \langle u'_i u'_j\rangle$ (a symmetric FiberTensor2), of which a per-component variance would be only the basis-dependent diagonal.
  • inner — the normalized L² inner product $\langle\cdot,\cdot\rangle$, a scalar that averages the fiber contraction over the $N$ grid cells or the $M$ points. l2norm and lpnorm are the norms derived from it, and weighted_inner is its spectral generalization, weighting the pairing by a kernel multiplier.
  • maximum, minimum, extrema — the $L^\infty$ end, extending Base. The bare forms take a scalar section; the mapped forms below lift that restriction for any order the reductions serve ($R \le 2$: scalar, vector and second-order tensor sections are the supported surface, and a fiber-preserving reduction raises above it rather than returning a wrong answer).
  • The mapped forms — integral, mean, maximum, minimum and extrema also accept a leading function, applied to the fiber value at every base point: mean(det, A) averages a determinant over the base and maximum(norm, u) takes a supremum of magnitude, each in a single pass that never builds the mapped quantity as a section. Naming that map is also what makes an order statistic well posed on a vector or tensor section, where the bare maximum refuses to guess. They mirror the standard-library mean(f, itr) and maximum(f, itr) spellings and, mapping the fiber nonlinearly, are physical-only.
  • radial_spectrum and radial_correlation — a Fourier-dual pair (Wiener–Khinchin) that resolves inner over a radial coordinate, the shell-binned power spectrum over $|k|$ and its physical-space two-point correlation over $|r|$, each also in a two-field co-spectrum form.

Physics stays consumer-side: the consumer builds kinetic energy, enstrophy, dissipation, rms, and turbulence intensities from these reductions.

Integral reductions

GBGPeriodicFields.Reductions.integral — Function
integral(f)
integral(fiber_map, f)

The base integral $\int f \,\mathrm{d}\mu$ of a section (integral $\equiv \int\,\mathrm{d}\mu$) — the measure-weighted sum of f over its base. It is the one extensive reduction, the only one that scales with the base measure; reach for inner or mean when you want an intensive, size-independent average instead. On a Grid3D the sum uses the uniform cell-volume quadrature, and on a PointSet it uses the unit-weight counting measure:

\[\int f \,\mathrm{d}\mu = \begin{cases} \dfrac{|\Omega|}{N} \sum_{x} f(x), & \text{base a } \texttt{Grid3D} \text{ — the box } \Omega \text{ and its } N \text{ cells},\\[4pt] \sum_{p} f_p, & \text{base a } \texttt{PointSet} \text{ — no domain, unit weight per point}, \end{cases}\]

where $N$ is the number of grid cells and $|\Omega|$ the domain volume. The result is fiber-preserving: a scalar for a scalar section, a FiberVector for a vector section, and a FiberTensor2 for a tensor section. For a band-limited field the grid quadrature is exact, because the periodic trapezoidal rule integrates the represented modes exactly. For a field in spectral representation the same value comes from the zero (DC) Fourier mode with no inverse transform, $\int_\Omega f\,\mathrm{d}\mu = \tfrac{|\Omega|}{N} \hat f(0)$, since the DC coefficient $\hat f(0) = \sum_x f(x)$ is real for a real field.

The mapped form

Given a leading function fiber_map, the integrand becomes that function of the section's fiber value at each base point rather than the fiber value itself:

\[\int_\Omega (\texttt{fiber\_map} \circ f) \,\mathrm{d}\mu.\]

The map receives the scalar for a scalar section, the FiberVector for a vector section, and the FiberTensor2 for a tensor section, so integral(det, A) integrates a determinant and integral(norm, u) a magnitude. The mapped value is formed one base point at a time and consumed by the reduction immediately, so nothing section-sized is built — where writing the same quantity as integral(det(A)) first materializes a whole determinant field. Passing identity recovers the bare form. The same leading function is taken by mean (which divides by the base count instead of weighting by the measure) and by maximum/minimum/extrema; for the order statistics it is also what makes them well posed above tensor order zero, the bare forms being scalar-only by design.

The mapped form is the cheaper route on both backends — one pass that allocates nothing, against a materialized section plus a second pass over it — by roughly two and a half times on a CPU and a quarter on a GPU. It gets there by different means on each, chosen internally: a fixed reduction tree over vectorized blocked loops on a CPU, a single fused pass on a GPU. That tree's shape does not depend on the thread count, so a CPU result is bitwise identical however many threads it runs on.

The fiber map's own cost can dominate

The fiber map's own cost can outweigh the choice of route. LinearAlgebra.norm applied to a fiber uses the overflow-safe scaled algorithm, several times the cost of the plain $\sqrt{\sum_i u_i^2}$ that the fieldwise norm evaluates, which is enough to make maximum(norm, u) costlier than lpnorm(u, Inf) on a CPU despite allocating nothing; passing a plain magnitude instead reverses that. Pick the map for the accuracy the result needs.

Inner-product and norm reductions

GBGPeriodicFields.Reductions.inner — Function
inner(f, g)

The normalized L² inner product $\langle f, g\rangle$ of two compatible sections (inner $\equiv \langle\cdot,\cdot\rangle$) — the fiber contraction $f \cdot g$ averaged over the base, returning a scalar. It is intensive (it matches mean), which makes it the natural pairing for homogeneous turbulence, where kinetic energy is $\tfrac{1}{2}\langle u, u\rangle$. For the norms derived from it use l2norm or lpnorm; to resolve the pairing over a wavenumber or separation shell use radial_spectrum or radial_correlation.

The arguments f and g are two compatible sections of equal tensor order. On a grid the pairing is the equal-weight average over the $N$ cells ($\Omega$ is the periodic box, $|\Omega|$ its volume); on a point-set it is the average over the $M$ points. The grid's continuum form below is exact when the product $f \cdot g$ is resolved on the grid (the periodic trapezoidal rule integrates resolved modes exactly); under aliasing — both fields carrying Nyquist content, say — the discrete sum is the definition:

\[\begin{aligned} \langle f, g\rangle &= \frac{1}{|\Omega|} \int_\Omega f(x) \cdot g(x)\,\mathrm{d}x = \frac{1}{N} \sum_x f(x) \cdot g(x) && (\texttt{Grid3D}), \\ \langle f, g\rangle &= \frac{1}{M} \sum_p f_p \cdot g_p && (\texttt{PointSet}). \end{aligned}\]

For two fields in spectral representation inner returns the same value by Parseval's theorem with no inverse transform, applying the rfft half-spectrum weighting internally. This $p = 2$ inner and l2norm are representation-invariant by Parseval, and integral/mean by the zero Fourier mode; lpnorm and maximum/minimum/extrema remain physical-only; std/var gained a scalar Parseval form.

The mixed spectral pair allocates one or two correction planes

In spectral representation inner(f, f) and l2norm run allocation-free, but the mixed inner(f, g) materializes $O(N^2)$ correction planes — the folded axis's zero plane always, and its Nyquist plane as well when that axis has even length, so an odd folded axis pays for one plane and an even one for two. That is small beside the $O(N^3)$ field, and it is paid per call, where inner(f, f) pays nothing. The fused alternative, a dot over a strided view, has no method on the AMD path (rocBLAS dotc), so one route serves every backend.

GBGPeriodicFields.Reductions.weighted_inner — Function
weighted_inner(f, w::SpectralKernel)
weighted_inner(f, g, w::SpectralKernel)
weighted_inner(f, weights::Tuple{Vararg{SpectralKernel}})

The multiplier-weighted L² inner product $\langle f, w g\rangle$ of two fields in spectral representation against a real Fourier multiplier w (weighted_inner $\equiv \langle\cdot, w \cdot\rangle$). It applies the spectral symbol w to g and reduces against f in a single fused pass, materializing no weighted field — the reduction-dual of convolve, which instead forms $w \star g$ as a field. It generalizes inner (the $w \equiv 1$ case); the two-argument form is the $g = f$ case $\langle f, w f\rangle$.

The arguments are:

  • f, g — two compatible, equal-order fields in spectral representation (g = f in the two-argument form).
  • weights — in the tuple form, a tuple of such kernels: every one is answered in a single traversal and one device readback, bitwise-equal to calling the operation once per weight, and the results are returned in the order given. An empty tuple answers () without reading the field, and every refusal the single-weight form makes is made here in any position.
  • w — the weight: a spectral kernel in any of its storage classes, holding a real multiplier $w(k)$. All four classes give bitwise-identical results, so the choice is one of storage only. The multiplier must be real, because $\langle f, w g\rangle$ is an inner product only then: a kernel whose type says complex — translation_kernel's phase, for one — is rejected rather than silently contributing its real part. One class is exempt, and the exemption is a hazard in its own right — see the warning below. Build it with the neutral builders: a band mask (spectral_band/spectral_cutoff) gives an in-band (co-)energy, and radial_kernel(identity, multipliers) ($w = |k|^2$) gives the Dirichlet energy $\langle f, -\Delta g\rangle$ exactly (both keep the true Nyquist $k^2$); on fields with no Nyquist content this equals $\langle\nabla f, \nabla g\rangle$, the derivative multiplier zeroing only the then-empty Nyquist plane.
The unit weight and `inner` agree numerically, not bitwise

$\langle f, 1 \cdot f\rangle$ is $\langle f, f\rangle$, so a unit weight reproduces inner — measured to within $10^{-15}$ relative, not to the last bit. Both reduce on the same threaded fixed tree, so the residue is the weighted pass carrying a multiplication by one through each mode rather than a different summation order. Worth knowing when replacing one with the other in code that compares against a stored number.

A complex `StoredKernel` weight is silently reduced to its real part

Three of the four kernel classes throw on a complex multiplier, their type settling the question for free. A StoredKernel cannot: its storage is Complex{T} by construction, so a materialized spectral_cutoff and a materialized translation_kernel have the same type. Telling them apart needs a full extra pass over the coefficients, which this reduction's single pass does not permit — so that class keeps the real-part behaviour, and a complex weight reaching it returns a number rather than raising. It is the one route by which a phase kernel can serve as a weight and answer a question you did not ask.

Spectral representation only, being a Parseval reduction like the spectral inner.

Physically it is the L² pairing of f with the filtered field $w \star g$. By Parseval, with the rfft half-spectrum weight $\alpha(k)$ ($1$ on the folded axis's zero plane and, when that axis has even length, its Nyquist plane; $2$ otherwise — the folded rfft axis is the layout's fft_dims[1], the first by default), $N$ the number of grid points, and $c$ a fiber-component index (unrelated to the exponent coefficient Convolution writes $c$),

\[\langle f, w g\rangle = \frac{1}{N} \sum_x f(x) \cdot (w \star g)(x) = \frac{1}{N^2} \sum_{\text{stored } k} \alpha(k) w(k) \sum_c \mathrm{Re}\bigl(\hat f_c(k) \overline{\hat g_c(k)}\bigr).\]

It equals the naive $\texttt{inner}(w \star f, w \star g)$ only when $w$ is an idempotent projection (a sharp band mask, $w^2 = w$); for a general $w$ it is the single-weight pairing $\langle f, w g\rangle$ above, not $\lVert w \star f\rVert^2$. The co-spectrum-like mixed form is symmetric in f, g and may be negative.

It is fused: the cost is a single weighted pass over the coefficients — the same traffic as one spectral inner, both reducing on the threaded fixed tree since the 2026-08-30 fix, so they agree as threads are added — and its only allocation is a small per-axis weight vector (one wavenumber row, not a field). It is thus far cheaper than the radial reductions radial_spectrum / radial_correlation, which sweep every mode with a scatter-add binning pass (and, for the correlation, an inverse transform).

GBGPeriodicFields.Reductions.l2norm — Function
l2norm(f)

The normalized L² norm $\lVert f\rVert_2$ of a section (l2norm $\equiv \lVert\cdot\rVert_2$) — the root-mean-square of the fiber magnitude $|f|$ over the base, and the $p = 2$ case of lpnorm. It is $\sqrt{\langle f, f\rangle}$ built on inner, so it inherits both bases: the grid cell-volume average and the point-set counting average.

\[\lVert f\rVert_2 = \sqrt{\langle f, f\rangle} = \sqrt{\frac{1}{N} \sum_x |f(x)|^2} \quad (\texttt{Grid3D}), \qquad \sqrt{\frac{1}{M} \sum_p |f_p|^2} \quad (\texttt{PointSet}).\]

It is defined for fields in physical representation and point-values, and — through the Parseval inner — for a field in spectral representation.

GBGPeriodicFields.Reductions.lpnorm — Function
lpnorm(f, p = 2)

The normalized $L^p$ norm $\lVert f\rVert_p$ of a section (lpnorm $\equiv \lVert\cdot\rVert_p$), where $|f|$ is the pointwise fiber magnitude (the fiberwise norm) — the $L^p$ average of $|f|$ over the base. The exponent p selects the norm: p = 2 (the default) reduces to l2norm, and p = Inf gives the supremum of the fiber magnitude (for example the maximum speed entering a CFL time-step bound). On a grid the average is the equal-weight sum over the $N$ cells; on a point-set it is the sum over the $M$ points:

\[\begin{aligned} \lVert f\rVert_p &= \Bigl(\frac{1}{N} \sum_x |f(x)|^p\Bigr)^{1/p} && (\texttt{Grid3D}), \\ \lVert f\rVert_p &= \Bigl(\frac{1}{M} \sum_i |f_i|^p\Bigr)^{1/p} && (\texttt{PointSet}), \\ \lVert f\rVert_\infty &= \sup_{x} |f(x)| = \max_x |f(x)|, && \end{aligned}\]

It is physical-space only at every exponent, p = 2 included; for a field in spectral representation use l2norm, which reads the same value off the coefficients through Parseval.

The exponent p must satisfy $1 \le p \le \infty$; outside that range the expression is not a norm and the call raises rather than returning a plausible number. The result carries the section's own element type — a Float32 section gives a Float32 norm at every exponent.

Moments and order statistics

These extend the standard-library generics — mean, std, var, and cov from Statistics, and maximum, minimum, and extrema from Base — rather than introducing package names, and are used exactly as their stdlib counterparts are. All seven are in scope from using GBGPeriodicFields alone: the Statistics four are re-exported by the umbrella, exactly as dot and norm are re-exported from LinearAlgebra, and the Base three are in scope already.

The four Statistics generics are re-exported by the umbrella, so they are public here; the three Base ones are not re-exported (they need no re-export, Base being in scope already), so they are collected by the unexported sweep instead. Two blocks, one group.

Statistics.cov — Function
cov(u; corrected = true)

The covariance tensor $R_{ij} = \langle u'_i u'_j\rangle$ of a vector section over its base, where $u' = u - \bar u$ is the fluctuation about the base mean — the coordinate-free second central moment of a vector-valued field or point set, the vector analogue of the scalar var. It returns one symmetric FiberTensor2: the diagonal holds the per-component variances (the normal stresses, in a turbulence reading), the off-diagonal the component covariances (the shear stresses) that a per-component variance would discard.

Use this for the second moment of a vector field. The var/std pair is deliberately scalar-only: a per-component var would be only the basis-dependent diagonal of this tensor, and $\operatorname{std} = \sqrt{\operatorname{var}}$ has no canonical vector form, so the covariance tensor is the honest object. The mean $\bar u$ is subtracted first, so this is the covariance of the fluctuations, not the raw second moment $\langle u_i u_j\rangle$.

The arguments are:

  • u — the vector section whose fluctuations the covariance tensor is built from.
  • corrected — divide by the base count minus one (the sample convention, the default, matching Statistics.cov); false divides by the count (the population covariance).

Physical-space only, since the outer product $u \otimes u$ is nonlinear. Computed in one fused mapped pass as $\texttt{mean}(u \otimes u) - \bar u \otimes \bar u$ (Bessel-scaled — divided by the base count minus one, as var is), over the grid cell-average measure and the point counting measure alike.

Statistics.mean — Function
mean(f)
mean(fiber_map, f)

The arithmetic average of a section over its base, fiber-preserving: on a grid the equal-weight cell average $\tfrac{1}{N}\sum_n f_n$ over the $N$ cells, on a point-set the sample mean $\tfrac{1}{M}\sum_p f_p$ over the $M$ points — a vector field's mean is one FiberVector, a second-order tensor field's one FiberTensor2. The mapped form mean(fiber_map, f) averages $(\texttt{fiber\_map} \circ f)(x_n)$ (for example mean(det, A)) in one fused pass with no intermediate section; the map is nonlinear in general, so the mapped forms exist on fields in physical representation and point-values only. On a field in spectral representation the mean is read from the zero (DC) Fourier mode in $O(1)$, equal to the physical value with no transform. See integral for the extensive (measure-weighted) sibling.

Statistics.std — Function
std(f; corrected = true)

The sample standard deviation of a scalar section: the square root of var, over the same bases var serves — a Grid3D or a PointSet — and, for a field, in spectral representation as well. Point values are representation-free, so that last clause reaches fields alone. Like var it is scalar-only — $\operatorname{std} = \sqrt{\operatorname{var}}$ has no canonical form for a vector (the matrix square root of the covariance is not a standard deviation); use cov for the vector second central moment.

The arguments are:

  • f — the scalar section the moment is taken over: a field in physical or spectral representation, or point values.
  • corrected — divide by the base count minus one (Bessel's correction, the default) rather than by the count, exactly as it does for var, of which this is the square root.

Statistics.var — Function
var(f; corrected = true)

The sample variance of a scalar section over its base: the Bessel-corrected mean (dividing by one less than the count, the standard correction that makes the sample variance an unbiased estimate of the population one) of the squared deviation from the average, $\tfrac{1}{N-1}\sum_n (f_n - \bar f)^2$ over a grid's $N$ cells and $\tfrac{1}{M-1}\sum_p$ over a point set's $M$ points (matching Statistics.var's default correction).

var/std are scalar-only: the sample variance is unambiguous only for a scalar section. A vector field's coordinate-free second moment is the covariance tensor cov; a per-component variance would be only its basis-dependent diagonal, so it is not offered — calling var/std on a vector or tensor section raises a clear error pointing to cov.

In physical representation it runs as two fused passes — the mean, then the squared deviations — with no intermediate deviation section (the numerically stable form). In spectral representation it is read from Parseval: the population moment is $\langle f, f\rangle - \langle f\rangle^2 = N^{-2}\sum_{\text{stored } k \ne 0} \alpha(k) |\hat f_k|^2$ — the fluctuation energy, with $N$ the number of grid cells, $\alpha(k)$ the half-spectrum multiplicity of mode $k$, and the $N^{-2}$ the normalization the inner product itself carries — and the default corrected = true multiplies it by $N/(N-1)$. Either way it equals the physical value with no inverse transform; that one-pass form loses precision to cancellation when the mean dominates the fluctuations, so prefer the physical form there.

The arguments are:

  • f — the scalar section the moment is taken over: a field in physical or spectral representation, or point values.
  • corrected — divide by the count minus one (the sample convention, the default, matching Statistics.var) or by the count itself. A grid holds the complete population of a field rather than a sample of it, so corrected = false is often what a field diagnostic wants; the default follows the standard library rather than the base.

See std for its square root, cov for the vector second moment, and mean for the first moment.

Radial reductions

GBGPeriodicFields.Reductions.radial_spectrum — Function
radial_spectrum(f, multipliers)
radial_spectrum(f, g, multipliers)

The radial (shell-binned) power spectrum resolves a field's L² energy over wavenumber-magnitude shells. Write $P(\kappa)$ for the one-argument power spectrum and $P_{fg}(\kappa)$ for the two-argument co-spectrum (cross-power) of two compatible, equal-order fields.

The arguments are:

  • f, g — the fields, in spectral representation; the two-argument form takes them compatible and of equal tensor order.
  • multipliers — the per-axis wavenumbers $k$ for the field's grid (FieldSpectralMultipliers).

This reduction acts on the spectral representation only, being a Parseval reduction like the spectral inner.

It returns (shells, spectrum), a pair of Vector{T} in the section's own scalar type and on the host whatever backend the field lives on (the shell accumulators are small and are brought back). Here shells are the bin-center wavenumber magnitudes $\kappa$ and spectrum[i] sums the Parseval-weighted fiber (co-)energy over the modes whose rounded magnitude falls in shell $i$:

\[\begin{gathered} P(\kappa_i) = \frac{1}{N^2} \sum_{\substack{k : \mathrm{round}(|k|/\Delta k) = i}} \alpha(k) \sum_c |\hat f_c(k)|^2, \\ P_{fg}(\kappa_i) = \frac{1}{N^2} \sum_{\substack{k : \mathrm{round}(|k|/\Delta k) = i}} \alpha(k) \sum_c \mathrm{Re}\bigl(\hat f_c(k) \overline{\hat g_c(k)}\bigr), \end{gathered}\]

with $c$ indexing the fiber components, $\alpha(k)$ the rfft half-spectrum Parseval weight ($1$ on the folded axis's zero and even-length Nyquist planes, $2$ otherwise — the folded rfft axis is the layout's fft_dims[1]), and shell width $\Delta k$ (the box fundamental). Each form refines inner: $\sum_\kappa P(\kappa) = \langle f, f\rangle$ and $\sum_\kappa P_{fg}(\kappa) = \langle f, g\rangle$ — the L² (co-)energy split across isotropic $|k|$-shells one fundamental wavenumber wide (the box's smallest nonzero wavenumber, $\Delta k = 2\pi / \max_a L_a$). The one-argument form is the $g = f$ case ($\mathrm{Re}(\hat f \overline{\hat f}) = |\hat f|^2$); the co-spectrum is symmetric ($P_{fg} = P_{gf}$, $\mathrm{Re}$ being conjugation-symmetric) and, unlike the power spectrum, may be negative in a shell (anticorrelated modes). The consumer's physics kinetic-energy spectrum is $E(\kappa) = \tfrac{1}{2} P(\kappa)$ (it integrates to the turbulent kinetic energy, half the L² energy); the package keeps the neutral power-spectrum name, physics stays consumer-side.

The shells are CENTRED on their nominal wavenumber — shell $m$ collects $\lvert k\rvert$ within $\pm\Delta k/2$ of $m\Delta k$ — which is what makes $\kappa_m$ an energy-density sample AT $\kappa_m$ rather than at the band's edge. The abscissa is a property of the grid alone, identical for every field on it, so two spectra are directly comparable and a co-spectrum (which may be negative) is handled by the same rule.

For an exact spectral moment, do not weight the abscissa

Reporting each shell's energy-weighted mean wavenumber would make the first moment $\sum_m \kappa_m E(\kappa_m)$ exact, but it is the wrong tool: the abscissa would then depend on the field, so two spectra on one grid would arrive on different $\kappa$ grids, and a co-spectrum would divide by a weight that can vanish or change sign. Take the moment directly instead — weighted_inner against a radial symbol is exact and involves no binning at all:

weighted_inner(f, radial_kernel(k2 -> sqrt(k2), multipliers))   # ⟨f, |k| f⟩, exactly
weighted_inner(f, radial_kernel(identity, multipliers))         # ⟨f, −Δf⟩, the Dirichlet energy

Shells run from $0$ to the corner wavenumber, so the sum covers all modes (an exact inner refinement); on a de-aliased field the high-$|k|$ shells are empty. On a non-cubic box the shells beyond the inscribed sphere of the sampled band — shell index $\min_a k_a^{\mathrm{Nyq}} / \Delta k$, with $k_a^{\mathrm{Nyq}} = \lfloor N_a/2 \rfloor 2\pi/L_a$ the per-axis Nyquist wavenumber — are incompletely sampled (only corner modes contribute), the standard isotropic-spectrum caveat; the total still equals inner. The shell width carries a second anisotropy artefact worth knowing: $\Delta k$ is taken from the box's largest side, so on a strongly anisotropic box it is finer than the mode spacing $2\pi/L_a$ along every shorter axis, and a systematic fraction of shells is then empty — the profile combs, though its sum is unaffected. The two shells meet at a half-integer $|k|/\Delta k$, which an anisotropic box hits exactly; such a mode is assigned by round's ties-to-even, so the boundary belongs to neither shell by a fixed convention but to whichever has even index. The interval is deliberately not written half-open for that reason — a half-open bracket would claim round-half-up, which is not what the code does. The reduction is GPU-portable: a single scatter-add binning pass over the modes that derives each mode's shell, fiber contraction, and Parseval weight from its index — no full-grid staging array is built — costing more than a plain reduction like inner only by the binning — whose accumulators take atomic (concurrency-safe) updates, since several modes land in one shell — and a square root per mode.

GBGPeriodicFields.Reductions.radial_correlation — Function
radial_correlation(f, plans)
radial_correlation(f, g, plans)

The radial (shell-averaged) two-point correlation of a field is the physical-space dual of radial_spectrum under the Wiener–Khinchin theorem — the statement that the autocorrelation and the power spectrum are a Fourier-transform pair. The one-argument form is the autocorrelation $C(r)$, and the two-argument form is the cross-correlation $C_{fg}(r) = \langle f(x)\cdot g(x+r)\rangle$ of two compatible, equal-order fields.

The arguments are:

  • f, g — the fields, in spectral representation; the two-argument form takes them compatible and of equal tensor order.
  • plans — transform plans for their grid and layout; a pair carries no tensor order and serves every rank.

It takes plans where its Fourier dual radial_spectrum takes multipliers, the one asymmetry in an otherwise mirrored pair: the spectrum weighs each mode where it already sits, while the correlation must come back to physical space, and an inverse transform needs a plan.

It returns (separations, correlation), a pair of host Vector{T} in the section's scalar type, as radial_spectrum does, where separations are the bin-center magnitudes $r$ and correlation[i] is the value averaged over the minimum-image shell (each separation taken as its nearest periodic replica, so no distance exceeds half the box) $|r| \approx r$. By the (cross-)correlation theorem the kernel forms the fiber-summed (cross-)power spectrum, inverse-transforms it, and normalizes:

\[\begin{gathered} C(r) = \frac{1}{N} \sum_x f(x)\cdot f(x+r) = \frac{1}{N} \mathcal F^{-1}\Bigl(\textstyle\sum_c |\hat f_c|^2\Bigr)(r), \\ C_{fg}(r) = \frac{1}{N} \sum_x f(x)\cdot g(x+r) = \frac{1}{N} \mathcal F^{-1}\Bigl(\textstyle\sum_c \overline{\hat f_c} \hat g_c\Bigr)(r), \end{gathered}\]

with $c$ indexing the fiber components, followed by the shell average $C(r_i) = |\text{shell } i|^{-1} \sum_{|r| \approx r_i} C(r)$. At zero separation each is inner: $C(0) = \langle |f|^2\rangle = \texttt{inner}(f, f)$ and $C_{fg}(0) = \langle f\cdot g\rangle = \texttt{inner}(f, g)$ — inner resolved over physical separation, exactly as radial_spectrum resolves it over $|k|$ (a Fourier pair up to the convention's $1/N$: $\mathcal F C = |\hat f|^2/N$, $\mathcal F C_{fg} = \overline{\hat f} \hat g/N$). The one-argument form is the $g = f$ case; the radial binning symmetrizes the cross-correlation — the $\pm r$ folding of the min-image shells averages $C_{fg}(r)$ with $C_{fg}(-r) = C_{gf}(r)$, so the result equals $\tfrac{1}{2}(C_{fg} + C_{gf})$ and is symmetric in $f, g$.

Separations run from $0$ to the minimum-image corner $\sqrt{\sum_a r_a^2}$, with the per-axis reach $r_a = \lfloor N_a/2\rfloor \Delta x_a$ ($= L_a/2$ on an even axis, half a cell less on an odd one; $\sqrt{3} L/2$ for an even cubic box) at the finest spacing $\min_a \Delta x_a$, the $\min(i, N_a - i)$ fold making $C$ periodic and even ($C(r) = C(L - r)$). This is the physical-space mirror of the spectrum's corner caveat: only $|r| \le \min_a r_a$ — the sphere inscribed in the min-image box — is sampled in all directions; shells from there out to the corner keep only the box-diagonal directions (incompletely sampled). And in a finite periodic box the large-$r$ tail is itself an artifact — there $C$ reflects the field correlating with its own periodic image, not a true infinite-domain correlation — so a consumer extracts an integral scale (the area under the normalized correlation curve) only out to where $C$ has decayed (e.g. the first zero crossing), not the full curve. As with the spectrum the total is unaffected: $C(0) = \texttt{inner}(f, f)$ exactly.

It takes spectral input only, since it needs the inverse transform, and it is GPU-portable: one inverse transform plus a single binning pass.

This one allocates a field, unlike `radial_spectrum`

Its route builds a full power field and takes an allocating inverse transform, so it costs a field's worth of memory per call — a deliberate exception to the package's allocation-free default, guarded by a bounded rather than a zero assertion; radial_spectrum has no such cost, its staging having been fused into the binning kernel, leaving only the shell accumulators.

source

Five of the reductions — integral, mean, maximum, minimum and extrema — also have a mapped form taking a leading function, applied to the fiber value at every base point — mean(det, A), maximum(norm, u) — which reduces a nonlinear invariant in one pass without building it as a section. That form is documented on integral, including when to prefer it on a CPU; mean, maximum, minimum, and extrema take the same leading function. Statistics gives var and std no such spelling, so neither does this package.

Internal API

These symbols are not part of the public interface; they are documented for contributors — the fiberwise reduction machinery (the fiber map-reduce and its loop and tree forms) and the fixed reduction tree that makes a threaded reduction bitwise thread-count-invariant, together with the backend split that decides which of the two a reduction takes.

GBGPeriodicFields.Reductions._fiber_loop_reduce — Method
_fiber_loop_reduce(fiber_map, combine, components, V, ::Val{NC}, lo, hi)

Reduce base points lo:hi on the CPU, assembling each fiber value of type V from components, applying fiber_map, and combining with combine. The recursion splits until a leaf of _FIBER_REDUCTION_BLOCK points, which runs as one vectorized loop.

The shape is Base's own mapreduce blocking, reproduced here because the generic path does not apply to a fused fiber gather: reducing the equivalent lazy Broadcasted forgoes the vectorized loop and runs several times slower, and the sequential alternative would give up pairwise summation's $O(\log n)$ error growth for $O(n)$.

source
GBGPeriodicFields.Reductions._fiber_mapreduce — Method
_fiber_mapreduce(fiber_map, combine, section)

Reduce with combine over the base, applying fiber_map to the fiber value at each base point: the scalar itself for tensor order 0, the FiberVector for 1, the FiberTensor2 for 2. This backs the mapped forms of the reductions, so a nonlinear fiber invariant is reduced without materializing it as a section — the mapped value exists only per base point, in registers.

The fiber is gathered from the section's per-component arrays, because the fiber-last layout makes each component a contiguous slice but places the components of one base point a whole base apart, so a fiber cannot be reinterpreted into a StaticArray in place. How those components are then reduced is chosen per backend by _reduce_fiber — a vectorized blocked loop on a CPU, one fused pass over a lazy Broadcasted on a GPU — since the two reward opposite things.

One spelling to avoid either way: the multi-argument mapreduce(fiber_map, combine, components...) is fused by GPUArrays but falls back on the CPU to a route that materializes a full section-sized array.

The fiber_map::FiberMap type parameter — here and on every public form that forwards to this one — is required, not decoration. Julia declines to specialize on an argument of Function type that a method only passes along instead of calling, so without it the map arrives boxed and the reduction allocates on every call; naming its type in the signature forces the specialization that keeps the whole family allocation-free.

GBGPeriodicFields.Reductions._fiber_tree_reduce — Method
_fiber_tree_reduce(fiber_map, combine, components, V, ::Val{NC}, lo, hi, depth)

Threaded form of _fiber_loop_reduce with the identical reduction tree: it splits at the same midpoints the serial recursion uses and combines left-before-right, evaluating the top depth levels as spawned tasks and every subtree below as the untouched serial recursion — so the result is bitwise-identical to serial at every thread count (the tree is a function of the element count alone, never of the schedule).

GBGPeriodicFields.Reductions._fiberwise — Method
_fiberwise(section, whole_reduce, over_base_reduce)

Apply a reduction that keeps the fiber and integrates the base away, returning a fiber value: a scalar for tensor order 0, a FiberVector for 1, a FiberTensor2 for 2. The whole_reduce(data) helper is used for the scalar case (reduce the whole array); over_base_reduce(data, base_dims) reduces only the leading base dimensions for higher orders. GBGPeriodicFields.Reductions._reduce_fiber — Function
_reduce_fiber(backend, fiber_map, combine, components, V, ::Val{NC})

Reduce a section's fiber values on backend, gathering each fiber of type V from its NC component arrays. The two backends take different routes because they reward opposite things: a CPU wants the vectorized blocked loop of _fiber_loop_reduce, while a GPU has no such loop to lose and is served by one fused pass over a lazy Broadcasted, which also spares it a section write and read-back.
