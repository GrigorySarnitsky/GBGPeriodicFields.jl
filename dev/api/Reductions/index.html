Reductions

GBGPeriodicFields.Reductions — Module
Reductions

The L² / measure structure on sections — the third operation family, alongside the fiberwise algebra and the differential operators. A reduction integrates a section over its base against the measure the base carries: a Grid3D uses its uniform quadrature (the cell volume), and a PointSet uses its counting measure (unit weight per point, forced because a PointSet is grid-free). One set of formulas serves both fields and point-values, dispatched on AbstractFiberSection.

The measure reductions act on physical fields and point-values — representation-free, physical-space quantities. Several also act on fields in spectral representation, returning the identical physical value with no inverse transform: inner/l2norm by Parseval's theorem, and integral/mean from the zero (DC) Fourier mode. The remaining reductions (lpnorm, std/var, maximum/minimum/extrema) stay physical-only.

Each family links to the home where its formula lives:

  • integral — the extensive integral, the one quantity that scales with the base measure.
  • mean, std, var — the intensive, fiber-preserving base moments (they extend Statistics; the mean of a vector field is a FiberVector): mean is the plain arithmetic average over the $N$ grid cells or the $M$ points, and std/var keep the Statistics keyword corrected = true (the default divides by the count minus one).
  • inner — the normalized L² inner product $\langle\cdot,\cdot\rangle$, a scalar that averages the fiber contraction over the $N$ grid cells or the $M$ points. l2norm and lpnorm are the norms derived from it, and weighted_inner is its multiplier-weighted spectral generalization $\langle f, w g\rangle$.
  • maximum, minimum, extrema — the $L^\infty$ end, extending Base. The bare forms take a scalar section; the mapped forms below extend them to every tensor order.
  • The mapped forms — each reduction above also accepts a leading function, applied to the fiber value at every base point: mean(det, A) averages a determinant over the base and maximum(norm, u) takes a supremum of magnitude, each in a single pass that never builds the mapped quantity as a section. Naming that map is also what makes an order statistic well posed on a vector or tensor section, where the bare maximum refuses to guess. They mirror the standard-library mean(f, itr) and maximum(f, itr) spellings and, mapping the fiber nonlinearly, are physical-only.
  • radial_spectrum and radial_correlation — a Fourier-dual pair (Wiener–Khinchin) that resolves inner over a radial coordinate, the shell-binned power spectrum over $|k|$ and its physical-space two-point correlation over $|r|$, each also in a two-field co-spectrum form.

Physics stays consumer-side: the consumer builds kinetic energy, enstrophy, dissipation, rms, and turbulence intensities from these reductions.

Integral reductions

GBGPeriodicFields.Reductions.integral — Function
integral(f)
integral(fiber_map, f)

The base integral $\int_\Omega f \,\mathrm{d}\mu$ of a section (integral $\equiv \int\,\mathrm{d}\mu$) — the measure-weighted sum of f over its base. It is the one extensive reduction, the only one that scales with the base measure; reach for inner or mean when you want an intensive, size-independent average instead. On a Grid3D the sum uses the uniform cell-volume quadrature, and on a PointSet it uses the unit-weight counting measure:

\[\int_\Omega f \,\mathrm{d}\mu = \frac{|\Omega|}{N} \sum_{x} f(x) \quad (\texttt{Grid3D}), \qquad \sum_{p} f_p \quad (\texttt{PointSet}),\]

where $N$ is the number of grid cells and $|\Omega|$ the domain volume. The result is fiber-preserving: a scalar for a scalar section, a FiberVector for a vector section, and a FiberTensor2 for a tensor section. For a band-limited field the grid quadrature is exact, because the periodic trapezoidal rule integrates the represented modes exactly. For a field in spectral representation the same value comes from the zero (DC) Fourier mode with no inverse transform, $\int_\Omega f\,\mathrm{d}\mu = \tfrac{|\Omega|}{N} \hat f(0)$, since the DC coefficient $\hat f(0) = \sum_x f(x)$ is real for a real field.

The mapped form

Given a leading function fiber_map, the integrand becomes that function of the section's fiber value at each base point rather than the fiber value itself:

\[\int_\Omega (\texttt{fiber\_map} \circ f) \,\mathrm{d}\mu.\]

The map receives the scalar for a scalar section, the FiberVector for a vector section, and the FiberTensor2 for a tensor section, so integral(det, A) integrates a determinant and integral(norm, u) a magnitude. The mapped value is formed one base point at a time and consumed by the reduction immediately, so nothing section-sized is built — where writing the same quantity as integral(det(A)) first materializes a whole determinant field. Passing identity recovers the bare form. The same leading function is taken by mean (which divides by the base count instead of weighting by the measure) and by maximum/minimum/extrema; for the order statistics it is also what makes them well posed above tensor order zero, the bare forms being scalar-only by design.

The mapped form is the cheaper route on both backends — one pass that allocates nothing, against a materialized section plus a second pass over it — by roughly two and a half times on a CPU and a quarter on a GPU. It gets there by different means on each, chosen internally: a vectorized blocked loop on a CPU, a single fused pass on a GPU.

Note

The fiber map's own cost can outweigh the choice of route. LinearAlgebra.norm applied to a fiber uses the overflow-safe scaled algorithm, several times the cost of the plain $\sqrt{\sum_i u_i^2}$ that the fieldwise norm evaluates, which is enough to make maximum(norm, u) dearer than lpnorm(u, Inf) on a CPU despite allocating nothing; passing a plain magnitude instead reverses that. Pick the map for the accuracy the result needs.

Inner-product and norm reductions

GBGPeriodicFields.Reductions.inner — Function
inner(f, g)

The normalized L² inner product $\langle f, g\rangle$ of two compatible sections (inner $\equiv \langle\cdot,\cdot\rangle$) — the fiber contraction $f \cdot g$ averaged over the base, returning a scalar. It is intensive (it matches mean), which makes it the natural pairing for homogeneous turbulence, where kinetic energy is $\tfrac{1}{2}\langle u, u\rangle$. For the norms derived from it use l2norm or lpnorm; to resolve the pairing over a wavenumber or separation shell use radial_spectrum or radial_correlation.

The arguments f and g are two compatible sections of equal fiber order. On a grid the pairing is the equal-weight average over the $N$ cells; on a point-set it is the average over the $M$ points:

\[\begin{aligned} \langle f, g\rangle &= \frac{1}{|\Omega|} \int_\Omega f(x) \cdot g(x)\,\mathrm{d}x = \frac{1}{N} \sum_x f(x) \cdot g(x) && (\texttt{Grid3D}), \\ \langle f, g\rangle &= \frac{1}{M} \sum_p f_p \cdot g_p && (\texttt{PointSet}). \end{aligned}\]

For two fields in spectral representation inner returns the same value by Parseval's theorem with no inverse transform, applying the rfft half-spectrum weighting internally. This $p = 2$ inner and l2norm are representation-invariant by Parseval, and integral/mean by the zero Fourier mode; lpnorm, std/var, and maximum/minimum/extrema remain physical-only.

GBGPeriodicFields.Reductions.weighted_inner — Function
weighted_inner(f, w)
weighted_inner(f, g, w)

The multiplier-weighted L² inner product $\langle f, w g\rangle$ of two fields in spectral representation against a real bounded Fourier multiplier w (weighted_inner $\equiv \langle\cdot, w \cdot\rangle$). It applies the spectral symbol w to g and reduces against f in a single fused pass, materializing no weighted field — the reduction-dual of convolve, which instead forms $w \star g$ as a field. It generalizes inner (the $w \equiv 1$ case); the two-argument form is the $g = f$ case $\langle f, w f\rangle$.

The arguments are:

  • f, g — two compatible, equal-order fields in spectral representation (g = f in the two-argument form).
  • w — the weight, a ScalarFieldSpectral holding a real multiplier $w(k)$ (only its real part is used). Build it with the neutral kernels: a band mask (spectral_band/spectral_cutoff) gives an in-band (co-)energy, and squared_wavenumber_field ($w = |k|^2$) gives the $H^1$/Dirichlet energy $\langle\nabla f, \nabla g\rangle$.

Physically it is the L² pairing of f with the filtered field $w \star g$. By Parseval, with the rfft half-spectrum weight $\alpha(k)$ ($1$ on the $k_x = 0$ and even-$N_x$ Nyquist planes, $2$ otherwise), $N$ the number of grid points, and $c$ indexing the fiber components,

\[\langle f, w g\rangle = \frac{1}{N} \sum_x f(x) (w \star g)(x) = \frac{1}{N^2} \sum_{k} \alpha(k) w(k) \sum_c \mathrm{Re}\bigl(\hat f_c(k) \overline{\hat g_c(k)}\bigr).\]

It equals the naive $\mathrm{inner}(w \star f, w \star g)$ only when $w$ is an idempotent projection (a sharp band mask, $w^2 = w$); for a general $w$ it is the single-weight pairing $\langle f, w g\rangle$ above, not $\lVert w \star f\rVert^2$. The co-spectrum-like mixed form is symmetric in f, g and may be negative.

Spectral representation only, being a Parseval reduction like the spectral inner. It is fused: the cost is a single weighted pass over the coefficients — comparable to one spectral inner — and its only allocation is a small per-axis weight vector (one wavenumber row, not a field). It is thus far cheaper than the radial reductions radial_spectrum / radial_correlation, which build an $O(N)$ shell-index array and a scatter-add binning pass (and, for the correlation, an inverse transform).

GBGPeriodicFields.Reductions.l2norm — Function
l2norm(f)

The normalized L² norm $\lVert f\rVert_2$ of a section (l2norm $\equiv \lVert\cdot\rVert_2$) — the root-mean-square of the fiber magnitude $|f|$ over the base, and the $p = 2$ case of lpnorm. It is $\sqrt{\langle f, f\rangle}$ built on inner, so it inherits both bases: the grid cell-volume average and the point-set counting average.

\[\lVert f\rVert_2 = \sqrt{\langle f, f\rangle} = \sqrt{\frac{1}{N} \sum_x |f(x)|^2} \quad (\texttt{Grid3D}), \qquad \sqrt{\frac{1}{M} \sum_p |f_p|^2} \quad (\texttt{PointSet}).\]

It is defined for physical fields and point-values, and — through the Parseval inner — for a field in spectral representation.

source
GBGPeriodicFields.Reductions.lpnorm — Function
lpnorm(f, p = 2)

The normalized $L^p$ norm $\lVert f\rVert_p$ of a section (lpnorm $\equiv \lVert\cdot\rVert_p$), where $|f|$ is the pointwise fiber magnitude (the fiberwise norm) — the $L^p$ average of $|f|$ over the base. The exponent p selects the norm: p = 2 (the default) reduces to l2norm, and p = Inf gives the supremum of the fiber magnitude (for example the maximum speed in a CFL condition). On a grid the average is the equal-weight sum over the $N$ cells; on a point-set it is the sum over the $M$ points:

\[\begin{aligned} \lVert f\rVert_p &= \Bigl(\frac{1}{|\Omega|} \int_\Omega |f(x)|^p\,\mathrm{d}x\Bigr)^{1/p} = \Bigl(\frac{1}{N} \sum_x |f(x)|^p\Bigr)^{1/p} && (\texttt{Grid3D}), \\ \lVert f\rVert_p &= \Bigl(\frac{1}{M} \sum_p |f_p|^p\Bigr)^{1/p} && (\texttt{PointSet}), \\ \lVert f\rVert_\infty &= \sup_{x} |f(x)| = \max_x |f(x)|. && \end{aligned}\]

It is physical-space only.

Radial reductions

GBGPeriodicFields.Reductions.radial_spectrum — Function
radial_spectrum(f, multipliers)
radial_spectrum(f, g, multipliers)

The radial (shell-binned) power spectrum resolves a field's L² energy over wavenumber-magnitude shells. Write $P(\kappa)$ for the one-argument power spectrum and $P_{fg}(\kappa)$ for the two-argument co-spectrum (cross-power) of two compatible, equal-order fields; f and g are in spectral representation and multipliers supplies the per-axis wavenumbers $k$ (FieldSpectralMultipliers). It returns (shells, spectrum), where shells are the bin-center wavenumber magnitudes $\kappa$ and spectrum[i] sums the Parseval-weighted fiber (co-)energy over the modes whose rounded magnitude falls in shell $i$:

\[\begin{gathered} P(\kappa_i) = \frac{1}{N^2} \sum_{\substack{k : \mathrm{round}(|k|/\Delta k) = i}} \alpha(k) \sum_c |\hat f_c(k)|^2, \\ P_{fg}(\kappa_i) = \frac{1}{N^2} \sum_{\substack{k : \mathrm{round}(|k|/\Delta k) = i}} \alpha(k) \sum_c \mathrm{Re}\bigl(\hat f_c(k) \overline{\hat g_c(k)}\bigr), \end{gathered}\]

with $c$ indexing the fiber components, $\alpha(k)$ the rfft half-spectrum Parseval weight ($1$ on the $k_x = 0$ and even-$N_x$ Nyquist planes, $2$ otherwise), and shell width $\Delta k$ (the box fundamental). Each form refines inner: $\sum_\kappa P(\kappa) = \langle f, f\rangle$ and $\sum_\kappa P_{fg}(\kappa) = \langle f, g\rangle$ — the L² (co-)energy split across isotropic $|k|$-shells of unit-fundamental width. The one-argument form is the $g = f$ case ($\mathrm{Re}(\hat f \overline{\hat f}) = |\hat f|^2$); the co-spectrum is symmetric ($P_{fg} = P_{gf}$, $\mathrm{Re}$ being conjugation-symmetric) and, unlike the power spectrum, may be negative in a shell (anticorrelated modes). The consumer's physics kinetic-energy spectrum is $E(\kappa) = \tfrac{1}{2} P(\kappa)$ (it integrates to the turbulent kinetic energy, half the L² energy); the package keeps the neutral power-spectrum name, physics stays consumer-side.

This reduction acts on the spectral representation only, being a Parseval reduction like the spectral inner. Shells run from $0$ to the corner wavenumber, so the sum covers all modes (an exact inner refinement); on a de-aliased field the high-$|k|$ shells are empty. For a non-cubic box the shells beyond $\min(N_i)/2$ are incompletely sampled (only corner modes contribute) — the standard isotropic-spectrum caveat — but the total still equals inner. The reduction is GPU-portable: a single scatter-add binning pass over the modes that derives each mode's shell, fiber contraction, and Parseval weight from its index — no full-grid staging array is built — costing more than a plain reduction like inner only by the atomic binning and a square root per mode.

GBGPeriodicFields.Reductions.radial_correlation — Function
radial_correlation(f, plans)
radial_correlation(f, g, plans)

The radial (shell-averaged) two-point correlation of a field is the physical-space Wiener–Khinchin dual of radial_spectrum. The one-argument form is the autocorrelation $C(r)$, and the two-argument form is the cross-correlation $C_{fg}(r) = \langle f(x)\cdot g(x+r)\rangle$ of two compatible, equal-order fields. The fields f (and g) are in spectral representation, and plans are their transform plans (matching the tensor order). It returns (separations, correlation), where separations are the bin-center magnitudes $r$ and correlation[i] is the value averaged over the minimum-image shell $|r| \approx r$. By the (cross-)correlation theorem the kernel forms the fiber-summed (cross-)power spectrum, inverse-transforms it, and normalizes:

\[\begin{gathered} C(r) = \frac{1}{N} \sum_x f(x)\cdot f(x+r) = \frac{1}{N} \mathcal F^{-1}\Bigl(\textstyle\sum_c |\hat f_c|^2\Bigr)(r), \\ C_{fg}(r) = \frac{1}{N} \sum_x f(x)\cdot g(x+r) = \frac{1}{N} \mathcal F^{-1}\Bigl(\textstyle\sum_c \overline{\hat f_c} \hat g_c\Bigr)(r), \end{gathered}\]

followed by the shell average $C(r_i) = |\text{shell } i|^{-1} \sum_{|r| \approx r_i} C(r)$. At zero separation each is inner: $C(0) = \langle |f|^2\rangle = \mathrm{inner}(f, f)$ and $C_{fg}(0) = \langle f\cdot g\rangle = \mathrm{inner}(f, g)$ — inner resolved over physical separation exactly as radial_spectrum resolves it over $|k|$ (a Fourier pair: $\mathcal F C = |\hat f|^2$, $\mathcal F C_{fg} = \overline{\hat f} \hat g$). The one-argument form is the $g = f$ case; the radial binning symmetrizes the cross-correlation — the $\pm r$ folding of the min-image shells averages $C_{fg}(r)$ with $C_{fg}(-r) = C_{gf}(r)$, so the result equals $\tfrac{1}{2}(C_{fg} + C_{gf})$ and is symmetric in $f, g$.

Separations run from $0$ to the minimum-image corner $\sqrt{\sum_a (L_a/2)^2}$ ($\sqrt{3} L/2$ for a cubic box) at the finest spacing $\min_a \Delta x_a$, the $\min(i, N_a - i)$ fold making $C$ periodic and even ($C(r) = C(L - r)$). This is the physical-space mirror of the spectrum's corner caveat: only $|r| \le \min_a L_a/2$ — the sphere inscribed in the min-image box — is sampled in all directions; shells from there out to the corner keep only the box-diagonal directions (incompletely sampled). And in a finite periodic box the large-$r$ tail is itself an artifact — there $C$ reflects the field correlating with its own periodic image, not a true infinite-domain correlation — so a consumer extracts an integral scale only out to where $C$ has decayed (e.g. the first zero crossing), not the full curve. As with the spectrum the total is unaffected: $C(0) = \mathrm{inner}(f, f)$ exactly.

It takes spectral input only, since it needs the inverse transform, and it is GPU-portable: one inverse transform plus a single binning pass.

source

The mean, std, and var moments (extending Statistics) and the maximum, minimum, and extrema order statistics (extending Base) are also defined for sections; they are method extensions of the standard-library generics rather than package exports, and are described in the module summary above.

Each reduction also has a mapped form taking a leading function, applied to the fiber value at every base point — mean(det, A), maximum(norm, u) — which reduces a nonlinear invariant in one pass without building it as a section. That form is documented on integral, including when to prefer it on a CPU; mean, maximum, minimum, and extrema take the same leading function. Statistics gives var and std no such spelling, so neither does this package.

Internal API

These symbols are not part of the public interface; they are documented for contributors — the base measure (count and cell measure) and the fiber-preserving reduction helper.

GBGPeriodicFields.Reductions._fiber_loop_reduce — Method
_fiber_loop_reduce(fiber_map, combine, components, V, ::Val{NC}, lo, hi)

Reduce base points lo:hi on the CPU, assembling each fiber value of type V from components, applying fiber_map, and combining with combine. The recursion splits until a leaf of _FIBER_REDUCTION_BLOCK points, which runs as one vectorized loop.

The shape is Base's own mapreduce blocking, reproduced here because the generic path does not apply to a fused fiber gather: reducing the equivalent lazy Broadcasted forgoes the vectorized loop and runs several times slower, and the sequential alternative would give up pairwise summation's $O(\log n)$ error growth for $O(n)$.

source
GBGPeriodicFields.Reductions._fiber_mapreduce — Method
_fiber_mapreduce(fiber_map, combine, section)

Reduce with combine over the base, applying fiber_map to the fiber value at each base point: the scalar itself for tensor order 0, the FiberVector for 1, the FiberTensor2 for 2. This backs the mapped forms of the reductions, so a nonlinear fiber invariant is reduced without materializing it as a section — the mapped value exists only per base point, in registers.

The fiber is gathered from the section's per-component arrays, because the fiber-last layout makes each component a contiguous slice but places the components of one base point a whole base apart, so a fiber cannot be reinterpreted into a StaticArray in place. How those components are then reduced is chosen per backend by _reduce_fiber — a vectorized blocked loop on a CPU, one fused pass over a lazy Broadcasted on a GPU — since the two reward opposite things.

One spelling to avoid either way: the multi-argument mapreduce(fiber_map, combine, components...) is fused by GPUArrays but falls back on the CPU to a route that materializes a full section-sized array.

The fiber_map::FiberMap type parameter — here and on every public form that forwards to this one — is required, not decoration. Julia declines to specialize on an argument of Function type that a method only passes along instead of calling, so without it the map arrives boxed and the reduction allocates on every call; naming its type in the signature forces the specialization that keeps the whole family allocation-free.

GBGPeriodicFields.Reductions._fiberwise — Method
_fiberwise(section, whole_reduce, over_base_reduce)

Apply a reduction that keeps the fiber and integrates the base away, returning a fiber value: a scalar for tensor order 0, a FiberVector for 1, a FiberTensor2 for 2. The whole_reduce(data) helper is used for the scalar case (reduce the whole array); over_base_reduce(data, base_dims) reduces only the leading base dimensions for higher orders. The (tiny) reduced array is copied to the host before the SVector/SMatrix build, so no device array is scalar-indexed.

GBGPeriodicFields.Reductions._reduce_fiber — Function
_reduce_fiber(backend, fiber_map, combine, components, V, ::Val{NC})

Reduce a section's fiber values on backend, gathering each fiber of type V from its NC component arrays. The two backends take different routes because they reward opposite things: a CPU wants the vectorized blocked loop of _fiber_loop_reduce, while a GPU has no such loop to lose and is served by one fused pass over a lazy Broadcasted, which also spares it a section write and read-back.
