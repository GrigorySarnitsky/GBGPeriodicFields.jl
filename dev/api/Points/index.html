Points

GBGPeriodicFields.Points — Module
Points

The unstructured base of the package's fiber-bundle model: off-grid sample positions and the field values there, as sections over a PointSet — the point-set counterpart of the grid sections in Fields (docs/ARCHITECTURE.md §2, §10).

Provided here:

  • Positions — Point (a single position; an alias of FiberVector) and PointSet (M positions in structure-of-arrays layout (M, 3), grid-free: periodicity is applied at transfer time).
  • Point-value sections — ScalarPointValues / VectorPointValues / TensorPointValues under AbstractPointValues <: AbstractFiberSection, mirroring the field tensor orders. They are representation-free: a point value is always a physical-space quantity.
  • Their full fiberwise algebra — the fields' physical surface (+, real scaling, scalar multiplication and division, dot, cross, mul!, transpose, norm, sym/skew/dev, with storage-wise broadcasting) — generated by reusing the FieldAlgebra code generators over the point-value section interface, so no per-component formula is written twice.

Transfer between these point sections and the grid — interpolation (grid to point) and its adjoint anterpolation (point to grid) — lives in the Interpolation module.

source

The Points module is the unstructured base of the package's fiber-bundle model: off-grid positions and the field values there, as sections over a PointSet (the point-set counterpart of the grid sections in Fields). It provides the data types and their full fiberwise algebra; the grid↔point transfer kernels live in the Interpolation module.

  • Positions — Point (a single coordinate triple, an alias of FiberVector) and PointSet (a structure-of-arrays collection of M positions, grid-free).
  • Point values — ScalarPointValues / VectorPointValues / TensorPointValues under AbstractPointValues: field values sampled at the M points, mirroring the field tensor orders, representation-free. Their fiberwise algebra (M2 + M3, storage-wise broadcasting) is generated by reusing the FieldAlgebra builders.

Types

GBGPeriodicFields.Points.AbstractPointValues — Type
AbstractPointValues{T<:AbstractFloat, R}

Abstract supertype for field values sampled at the M positions of a PointSet. T is the real scalar type; R is the tensor order (an integer value parameter). Point values are representation-free — a sampled value is always a physical-space quantity, so there is no physical/spectral distinction here, unlike the field types. Concrete subtypes: ScalarPointValues (R = 0), VectorPointValues (R = 1), TensorPointValues (R ≥ 2).

source
GBGPeriodicFields.Points.Point — Type
Point{T} = SVector{3, T}

A single position in the domain — a coordinate triple. Point is the base-space analog of FiberVector: the same SVector{3,T} representation, a different role (a location, not a field value). It is an alias, not a wrapper, so arithmetic on positions stays StaticArrays-native; the position/value distinction is one of role, not dispatch.

source
GBGPeriodicFields.Points.PointSet — Type
PointSet(coordinates::AbstractArray{T, 2}) where {T<:AbstractFloat}

A collection of M off-grid positions, stored structure-of-arrays in coordinates with shape (M, 3) — point index first, coordinate last, mirroring the fiber-last field layout so each coordinate axis is contiguous across points. Backend-generic: coordinates may be any AbstractArray (CPU Array, GPU CuArray/ROCArray). Grid-free — a periodic domain wraps any coordinate, so positions are not tied to a grid; a transfer operator takes the grid from the field.

TensorPointValues(data::AbstractArray{T}) where {T<:AbstractFloat}

Tensor field values of order R at M points, stored structure-of-arrays in data with shape (M, fiber_shape(Val(R))...) (e.g. (M, 3, 3) for R = 2). The constructor without an explicit {R} infers R = ndims(data) - 1.

GBGPeriodicFields.Points.PointValuesBroadcastStyle — Type
PointValuesBroadcastStyle{N}

Broadcast style for point values (N = 1 + tensor_order: (M,) / (M,3) / (M,3,3)). A PointValues stands for its storage array inside a broadcast; the style materializes the result back into a PointValues.
