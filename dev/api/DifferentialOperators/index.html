DifferentialOperators

GBGPeriodicFields.DifferentialOperators — Module
DifferentialOperators

Differential operators on scalar, vector, and tensor fields on three-dimensional rectangular periodic domains: gradient $\equiv \nabla$, divergence $\equiv \nabla\cdot$, curl $\equiv \nabla\times$, laplacian $\equiv \Delta$, inverse_laplacian $\equiv \Delta^{-1}$, and helmholtz_projection $\equiv \mathbb P$ (the Leray projection onto the divergence-free subspace).

The implemented methods act on fields in spectral representation. A field is its finite Fourier representation — the physical values are the trigonometric polynomial

\[f(x) = \sum_{k} \hat f(k)\, e^{i k \cdot x}\]

over the grid's represented modes (coefficients beyond the grid are zero by definition, not truncated). Each operator is therefore the exact term-by-term derivative of that polynomial, realized as a coefficientwise multiply by its wavenumber symbol — $\widehat{\partial_{x_j} f}(k) = i k_j\, \hat f(k)$, $\widehat{\Delta f}(k) = -|k|^2\, \hat f(k)$ — with no finite-difference truncation. The per-operator docstrings give the symbol each one applies; the = is genuine (the only deliberate departure is the Nyquist zeroing of the first-derivative wavenumbers on even-length axes, invariant 5). Each formula mirrors the coefficientwise kernel it documents, so the two can be checked against each other.

source

The DifferentialOperators module provides spectral differential operators on the fields defined in Fields: gradient ($\nabla$), divergence ($\nabla\cdot$), curl ($\nabla\times$), laplacian ($\Delta$), inverse_laplacian ($\Delta^{-1}$), and helmholtz_projection ($\mathbb P$), each with an in-place ! form and an allocating form.

The operators act on fields in spectral representation and are coefficientwise: differentiation is multiplication by the wavenumber multipliers held in a FieldSpectralMultipliers (built from a field with FieldSpectralMultipliers(field), or from the explicit six-array constructor). The laplacian, inverse_laplacian, and helmholtz_projection are representation-preserving; gradient/divergence/curl change tensor order as the operator dictates.

The Nyquist convention is handled by the multipliers (see FieldSpectralMultipliers in Fields): first-derivative wavenumbers are zeroed at the Nyquist mode on even-length axes, while squared wavenumbers keep the true $k^2$.

  destination::VectorFieldSpectral,

Compute the curl (curl $\equiv \nabla\times$) of a vector field in spectral representation in-place; returns destination. Coefficientwise, $\widehat{\nabla\times u}(k) = i\, k \times \hat u(k)$, i.e. componentwise (matching the kernel):

\[\widehat{(\nabla\times u)_1}(k) = i\,(k_2 \hat u_3 - k_3 \hat u_2), \quad \widehat{(\nabla\times u)_2}(k) = i\,(k_3 \hat u_1 - k_1 \hat u_3), \quad \widehat{(\nabla\times u)_3}(k) = i\,(k_1 \hat u_2 - k_2 \hat u_1).\]

Compute the divergence (divergence $\equiv \nabla\cdot$) of a field in spectral representation in-place; returns destination. A vector field $u$ gives the scalar $\nabla\cdot u = \partial_{x_i} u_i$; a second-order tensor field $A$ gives the vector $(\nabla\cdot A)_i = \partial_{x_j} A_{ij}$. Computed as the coefficientwise contraction with $i k$ (the kernel sums $i k_j \hat{(\cdot)}_j$ over the three axes):

\[\widehat{\nabla\cdot u}(k) = i\,(k_1 \hat u_1 + k_2 \hat u_2 + k_3 \hat u_3), \qquad \widehat{(\nabla\cdot A)_i}(k) = i\,(k_1 \hat A_{i1} + k_2 \hat A_{i2} + k_3 \hat A_{i3}).\]

Compute the gradient (gradient $\equiv \nabla$) of a field in spectral representation in-place; returns destination. A scalar field $\varphi$ gives the vector $(\nabla\varphi)_i = \partial_{x_i}\varphi$; a vector field $u$ gives the second-order tensor $(\nabla u)_{ij} = \partial_{x_j} u_i$. Computed coefficientwise (each source component multiplied by $i k$ of the differentiation axis):

\[\widehat{(\nabla\varphi)_i}(k) = i\, k_i\, \hat\varphi(k), \qquad \widehat{(\nabla u)_{ij}}(k) = i\, k_j\, \hat u_i(k).\]

GBGPeriodicFields.DifferentialOperators.helmholtz_projection — Function
helmholtz_projection(field::VectorFieldSpectral, multipliers::FieldSpectralMultipliers)

Allocate and return the Helmholtz (Leray) projection $\mathbb P$ of a vector field in spectral representation: $\widehat{(\mathbb P u)}_i(k) = (\delta_{ij} - k_i k_j/|k|^2)\,\hat u_j(k)$.

The returned vector field is the divergence-free part of field, with the zero Fourier mode left unchanged.

source
GBGPeriodicFields.DifferentialOperators.helmholtz_projection! — Function
helmholtz_projection!(
  destination::VectorFieldSpectral,
  field::VectorFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

Compute the Helmholtz (Leray) projection (helmholtz_projection $\equiv \mathbb P$) of a vector field in spectral representation in-place; returns destination. It removes the longitudinal (curl-free) part coefficientwise, leaving the divergence-free part — the kernel subtracts $k_i\,(k\cdot\hat u)/|k|^2$ from $\hat u_i$:

\[\widehat{(\mathbb P u)}_i(k) = \Bigl(\delta_{ij} - \frac{k_i k_j}{|k|^2}\Bigr)\, \hat u_j(k), \qquad k \ne 0,\]

and leaves the zero Fourier mode unchanged.

GBGPeriodicFields.DifferentialOperators.inverse_laplacian — Function
inverse_laplacian(field::AbstractFieldSpectral, multipliers::FieldSpectralMultipliers)

Allocate and return the zero-mean inverse Laplacian $\Delta^{-1}$ ($\widehat{\Delta^{-1} f}(k) = -\hat f(k)/|k|^2$ for $k \ne 0$, zero mode set to zero) of a field in spectral representation.

This operation is representation-preserving: scalar fields return scalar fields, vector fields return vector fields, and tensor fields return tensor fields of the same tensor order.

GBGPeriodicFields.DifferentialOperators.inverse_laplacian! — Function
inverse_laplacian!(
  destination::AbstractFieldSpectral,
  field::AbstractFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

Compute the zero-mean inverse Laplacian (inverse_laplacian $\equiv \Delta^{-1}$) of a field in spectral representation in-place; returns destination. Representation-preserving and coefficientwise — the kernel divides by $-|k|^2$ away from the origin and zeroes the mean mode:

\[\widehat{\Delta^{-1} f}(k) = \begin{cases} -\,\hat f(k) / |k|^2, & k \ne 0, \\ 0, & k = 0. \end{cases}\]

GBGPeriodicFields.DifferentialOperators.laplacian! — Function
laplacian!(
  destination::AbstractFieldSpectral,
  field::AbstractFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

Compute the Laplacian (laplacian $\equiv \Delta$) of a field in spectral representation in-place; returns destination. Representation-preserving and coefficientwise — for every scalar, vector, or tensor component the kernel multiplies by $-|k|^2$:

\[\widehat{\Delta f}(k) = -|k|^2\, \hat f(k), \qquad |k|^2 = k_1^2 + k_2^2 + k_3^2.\]
