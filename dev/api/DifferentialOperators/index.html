DifferentialOperators

GBGPeriodicFields.DifferentialOperators — Module
DifferentialOperators

Spectral differential operators on scalar, vector, and tensor fields over three-dimensional rectangular periodic domains. A field in this module is its finite Fourier representation, so each operator is the exact term-by-term derivative of that trigonometric polynomial, realized as a coefficientwise multiply by a wavenumber symbol with no finite-difference truncation. The wavenumber symbols are held in a FieldSpectralMultipliers, built from a field with FieldSpectralMultipliers(field) or from the explicit six-array constructor. Every operator provides an allocating form and an in-place ! form, and each per-operator docstring gives both the physical-space meaning and the spectral symbol it applies.

The operation families are:

  • gradient $\equiv \nabla$ raises the tensor order: a scalar field becomes a vector field, and a vector field becomes a second-order tensor field.
  • divergence $\equiv \nabla\cdot$ lowers the tensor order: a vector field becomes a scalar field, and a second-order tensor field becomes a vector field.
  • curl $\equiv \nabla\times$ returns the local rotation rate of a vector field and preserves the tensor order.
  • symmetric_gradient $\equiv \operatorname{sym}\nabla$ returns the symmetric part of a vector field's gradient as a second-order tensor field, formed directly without the full gradient — the fused symmetric peer of curl.
  • laplacian $\equiv \Delta$ applies the second-derivative operator to every component and preserves the tensor order.
  • inverse_laplacian $\equiv \Delta^{-1}$ returns the zero-mean solution of Poisson's equation and preserves the tensor order.
  • helmholtz_projection $\equiv \mathbb P$ projects a vector field onto its divergence-free part.

The Nyquist frequency is treated differently by symbol: first-derivative wavenumbers are zeroed at the Nyquist frequency on even-length axes, while squared wavenumbers keep the true squared wavenumber there.

GBGPeriodicFields.DifferentialOperators.gradient! — Function
gradient!(
  destination::VectorFieldSpectral,
  field::ScalarFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

gradient!(
  destination::TensorFieldSpectral{2},
  field::VectorFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

Compute the gradient (gradient $\equiv \nabla$) of a field and write it into destination, returning destination. Differentiating raises the tensor order by one: a scalar field $\varphi$ gives the vector field with components $(\nabla\varphi)_i = \partial_{x_i}\varphi$, and a vector field $u$ gives the second-order tensor field with components $(\nabla u)_{ij} = \partial_{x_j} u_i$.

Use this in-place form when destination is already allocated; the allocating gradient returns a fresh result instead.

The arguments are:

  • destination — the field that receives the result; it shares the domain of field and holds one tensor order higher.
  • field — the field to differentiate, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

Each output component is the source component multiplied coefficientwise by $\mathrm{i}$ times the wavenumber of the differentiation axis:

\[\widehat{(\nabla\varphi)_i}(k) = \mathrm{i}\, k_i\, \hat\varphi(k), \qquad \widehat{(\nabla u)_{ij}}(k) = \mathrm{i}\, k_j\, \hat u_i(k).\]

Compute the divergence (divergence $\equiv \nabla\cdot$) of a field and write it into destination, returning destination. Differentiating lowers the tensor order by one: a vector field $u$ gives the scalar field $\nabla\cdot u = \partial_{x_i} u_i$, and a second-order tensor field $A$ gives the vector field with components $(\nabla\cdot A)_i = \partial_{x_j} A_{ij}$.

Use this in-place form when destination is already allocated; the allocating divergence returns a fresh result instead.

The arguments are:

  • destination — the field that receives the result; it shares the domain of field and holds one tensor order lower.
  • field — the field to differentiate, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

The result is the coefficientwise contraction of the source with $\mathrm{i}$ times the wavenumber vector, summed over the three axes:

\[\widehat{\nabla\cdot u}(k) = \mathrm{i}\,(k_1 \hat u_1 + k_2 \hat u_2 + k_3 \hat u_3), \qquad \widehat{(\nabla\cdot A)_i}(k) = \mathrm{i}\,(k_1 \hat A_{i1} + k_2 \hat A_{i2} + k_3 \hat A_{i3}).\]

GBGPeriodicFields.DifferentialOperators.curl! — Function
curl!(
  destination::VectorFieldSpectral,
  field::VectorFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

Compute the curl (curl $\equiv \nabla\times$) of a vector field and write it into destination, returning destination. The curl is the vector field whose components are, with $\varepsilon_{ijk}$ the Levi-Civita symbol, $(\nabla\times u)_i = \varepsilon_{ijk}\, \partial_{x_j} u_k$; written out cyclically,

\[\begin{gathered} (\nabla\times u)_1 = \partial_{x_2} u_3 - \partial_{x_3} u_2, \\ (\nabla\times u)_2 = \partial_{x_3} u_1 - \partial_{x_1} u_3, \\ (\nabla\times u)_3 = \partial_{x_1} u_2 - \partial_{x_2} u_1. \end{gathered}\]

Use this in-place form when destination is already allocated; the allocating curl returns a fresh result instead.

The arguments are:

  • destination — the vector field that receives the result; it shares the domain of field.
  • field — the vector field to differentiate, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

The spectral symbol is a coefficientwise multiply by $\mathrm{i}$ times the cross product with the wavenumber vector, $\widehat{\nabla\times u}(k) = \mathrm{i}\, k \times \hat u(k)$, componentwise:

\[\begin{gathered} \widehat{(\nabla\times u)_1}(k) = \mathrm{i}\,(k_2 \hat u_3 - k_3 \hat u_2), \\ \widehat{(\nabla\times u)_2}(k) = \mathrm{i}\,(k_3 \hat u_1 - k_1 \hat u_3), \\ \widehat{(\nabla\times u)_3}(k) = \mathrm{i}\,(k_1 \hat u_2 - k_2 \hat u_1). \end{gathered}\]

GBGPeriodicFields.DifferentialOperators.symmetric_gradient! — Function
symmetric_gradient!(
  destination::TensorFieldSpectral{2},
  field::VectorFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

Compute the symmetric gradient (symmetric_gradient $\equiv \operatorname{sym}\nabla$) of a vector field and write it into destination, returning destination. It is the symmetric part of the gradient $\nabla u$, the second-order tensor field

\[S_{ij} = \tfrac12\,(\partial_{x_j} u_i + \partial_{x_i} u_j),\]

formed directly. It is the fused symmetric peer of curl, which extracts the antisymmetric part of $\nabla u$ as a vector: forming $S$ this way skips the full nine-component gradient tensor that sym(gradient(u)) builds only to symmetrize, so reach for it whenever the symmetric part is all you need.

Use this in-place form when destination is already allocated; the allocating symmetric_gradient returns a fresh result instead.

The arguments are:

  • destination — the second-order tensor field that receives the result; it shares the domain of field and holds one tensor order higher.
  • field — the vector field to differentiate, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

The spectral symbol symmetrizes $\mathrm{i}\,k_j\,\hat u_i$ in its two indices:

\[\widehat{S_{ij}}(k) = \tfrac{\mathrm{i}}{2}\,\bigl(k_j\,\hat u_i(k) + k_i\,\hat u_j(k)\bigr).\]

Second-order differential operators

GBGPeriodicFields.DifferentialOperators.laplacian! — Function
laplacian!(
  destination::AbstractFieldSpectral,
  field::AbstractFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

Compute the Laplacian (laplacian $\equiv \Delta$) of a field and write it into destination, returning destination. The Laplacian is a local operator: it sums the second partial derivatives of a scalar field $f$ over the three axes, and it acts on each component of a vector or tensor field alike, so it preserves the tensor order:

\[\Delta f = \partial^2_{x_i x_i} f, \qquad (\Delta u)_j = \partial^2_{x_i x_i} u_j.\]

Use this in-place form when destination is already allocated; the allocating laplacian returns a fresh result instead.

The arguments are:

  • destination — the field that receives the result; it matches the domain and tensor order of field.
  • field — the field to differentiate, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

The spectral symbol is a coefficientwise multiply by $-|k|^2$:

\[\widehat{\Delta f}(k) = -|k|^2\, \hat f(k), \qquad |k|^2 = k_1^2 + k_2^2 + k_3^2.\]

GBGPeriodicFields.DifferentialOperators.inverse_laplacian! — Function
inverse_laplacian!(
  destination::AbstractFieldSpectral,
  field::AbstractFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

Compute the zero-mean inverse Laplacian (inverse_laplacian $\equiv \Delta^{-1}$) of a field and write it into destination, returning destination. The result is the zero-mean field $\psi$ that solves Poisson's equation $\Delta\psi = f$; because the Laplacian annihilates constants, the solution is fixed uniquely by requiring its mean to vanish:

\[\Delta\psi = f, \qquad \int_\Omega \psi \, dx = 0.\]

For a vector or tensor field the same solve is applied to each component, so the tensor order is preserved.

Warning

As the inverse of a differential operator, $\Delta^{-1}$ is nonlocal: unlike the Laplacian it has no local partial-derivative formula, and the value at any point depends on the whole field.

Use this in-place form when destination is already allocated; the allocating inverse_laplacian returns a fresh result instead.

The arguments are:

  • destination — the field that receives the result; it matches the domain and tensor order of field.
  • field — the field to invert, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

The spectral symbol divides by $-|k|^2$ away from the origin and sets the zero Fourier mode to zero:

\[\widehat{\Delta^{-1} f}(k) = \begin{cases} -\,\hat f(k) / |k|^2, & k \ne 0, \\ 0, & k = 0. \end{cases}\]

Projection operators

GBGPeriodicFields.DifferentialOperators.helmholtz_projection! — Function
helmholtz_projection!(
  destination::VectorFieldSpectral,
  field::VectorFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

Compute the Helmholtz (Leray) projection (helmholtz_projection $\equiv \mathbb P$) of a vector field and write it into destination, returning destination. The projection removes the longitudinal (curl-free) part of the field and keeps the divergence-free part, subtracting the gradient of the pressure-like potential that solves the divergence:

\[\mathbb P u = u - \nabla\, \Delta^{-1}(\nabla\cdot u).\]

Warning

The inverse Laplacian $\Delta^{-1}$ is nonlocal, so $\mathbb P$ is a nonlocal operator in physical space even though it acts coefficientwise in spectral representation.

Use this in-place form when destination is already allocated; the allocating helmholtz_projection returns a fresh result instead.

The arguments are:

  • destination — the vector field that receives the result; it shares the domain of field.
  • field — the vector field to project, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

The spectral symbol subtracts the longitudinal part $k_i\,(k\cdot\hat u)/|k|^2$ from $\hat u_i$ at every nonzero wavevector, and leaves the zero Fourier mode unchanged:

\[\widehat{(\mathbb P u)}_i(k) = \Bigl(\delta_{ij} - \frac{k_i k_j}{|k|^2}\Bigr)\, \hat u_j(k), \qquad k \ne 0.\]
