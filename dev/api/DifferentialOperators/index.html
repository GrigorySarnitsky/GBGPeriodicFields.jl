DifferentialOperators

GBGPeriodicFields.DifferentialOperators — Module
DifferentialOperators

Spectral differential operators on scalar, vector, and tensor fields over three-dimensional rectangular periodic domains. A field in this module is its finite Fourier representation, so each operator is the exact term-by-term derivative of that trigonometric polynomial, realized as a coefficientwise multiply by a wavenumber symbol with no finite-difference truncation. The wavenumber symbols are held in a FieldSpectralMultipliers, built from a field with FieldSpectralMultipliers(field) or from the explicit six-array constructor. Every operator provides an allocating form and an in-place ! form, and each per-operator docstring gives both the physical-space meaning and the spectral symbol it applies.

The parts are:

  • gradient $\equiv \nabla$ raises the tensor order: a scalar field becomes a vector field, and a vector field becomes a second-order tensor field.
  • divergence $\equiv \nabla\cdot$ lowers the tensor order: a vector field becomes a scalar field, and a second-order tensor field becomes a vector field; an optional kernel argument composes a convolution into the same pass.
  • curl $\equiv \nabla\times$ returns the curl of a vector field, which measures its local rotation at twice the angular rate — the rate itself is $\tfrac{1}{2}\nabla\times u$ — and preserves the tensor order. (A fluid-dynamics consumer calls $\nabla\times u$ the vorticity; the package keeps the neutral mathematical name, as it does for symmetric_gradient against "strain rate".)
  • symmetric_gradient $\equiv \operatorname{sym}\nabla$ returns the symmetric part of a vector field's gradient as a second-order tensor field, formed directly without the full gradient — the fused symmetric peer of curl.
  • laplacian $\equiv \Delta$ applies the second-derivative operator to every component and preserves the tensor order.
  • inverse_laplacian $\equiv \Delta^{-1}$ returns the zero-mean solution of Poisson's equation and preserves the tensor order.
  • helmholtz_projection $\equiv \mathbb P$ projects a vector field onto its divergence-free part, in one pass whose destination may alias its source; an optional kernel argument composes a convolution into the same pass.

The Nyquist frequency is treated differently by symbol: first-derivative wavenumbers are zeroed at the Nyquist frequency on even-length axes, while squared wavenumbers keep the true squared wavenumber there.

Compute the gradient (gradient $\equiv \nabla$) of a field and write it into destination, returning destination. Differentiating raises the tensor order by one: a scalar field $\varphi$ gives the vector field with components $(\nabla\varphi)_i = \partial_{x_i}\varphi$, and a vector field $u$ gives the second-order tensor field with components $(\nabla u)_{ij} = \partial_{x_j} u_i$.

Use this in-place form when destination is already allocated; the allocating gradient returns a fresh result instead.

The arguments are:

  • destination — the field that receives the result; it shares the domain of field and holds one tensor order higher.
  • field — the field to differentiate, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

Each output component is the source component multiplied coefficientwise by $\mathrm{i}$ times the wavenumber of the differentiation axis:

\[\widehat{(\nabla\varphi)_i}(k) = \mathrm{i} k_i \hat\varphi(k), \qquad \widehat{(\nabla u)_{ij}}(k) = \mathrm{i} k_j \hat u_i(k).\]

Compute the divergence (divergence $\equiv \nabla\cdot$) of a field and write it into destination, returning destination. Differentiating lowers the tensor order by one: a vector field $u$ gives the scalar field $\nabla\cdot u = \partial_{x_i} u_i$, and a second-order tensor field $A$ gives the vector field with components $(\nabla\cdot A)_i = \partial_{x_j} A_{ij}$.

Use this in-place form when destination is already allocated; the allocating divergence returns a fresh result instead.

The arguments are:

  • destination — the field that receives the result; it shares the domain of field and holds one tensor order lower.
  • field — the field to differentiate, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

The result is the coefficientwise contraction of the source with $\mathrm{i}$ times the wavenumber vector, summed over the three axes:

\[\widehat{\nabla\cdot u}(k) = \mathrm{i} (k_1 \hat u_1 + k_2 \hat u_2 + k_3 \hat u_3), \qquad \widehat{(\nabla\cdot A)_i}(k) = \mathrm{i} (k_1 \hat A_{i1} + k_2 \hat A_{i2} + k_3 \hat A_{i3}).\]

The kernel-composed form

Passing a kernel composes the divergence with a periodic convolution in the same fused pass. As a real physical object the result is the kernel-weighted local average of the divergence, $g \star (\nabla\cdot u)$ — a single operator, because convolution and divergence both act coefficientwise in spectral representation, so their symbols simply multiply. The additional arguments are:

  • kernel — the kernel's transfer function $\hat g$, in any storage class of a SpectralKernel — a StoredKernel holding one coefficient per mode, or a compressed class evaluated per mode (radial, separable, or their product), which costs $O(N)$ or a closure rather than $O(N^3)$, exactly as convolve! takes it (including its reality condition on $\hat g$); it may alias destination, since the product is coefficientwise.
  • α, β — real accumulation weights as in convolve!: the four-argument form overwrites ($\alpha = 1$, $\beta = 0$), and the six-argument form computes

\[\widehat{\texttt{destination}}(k) = \alpha \hat g(k) \widehat{\nabla\cdot u}(k) + \beta \widehat{\texttt{destination}}(k),\]

and likewise per component for a second-order tensor field. The composed form replaces a divergence! followed by a convolve! — one fused pass instead of two, saving a full read and a full write of destination per call.

GBGPeriodicFields.DifferentialOperators.curl! — Function
curl!(
  destination::VectorFieldSpectral,
  field::VectorFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

Compute the curl (curl $\equiv \nabla\times$) of a vector field $u$ and write it into destination, returning destination. The curl is the vector field whose components are, with $\varepsilon_{ijk}$ the Levi-Civita symbol, $(\nabla\times u)_i = \varepsilon_{ijk} \partial_{x_j} u_k$; written out cyclically,

\[\begin{gathered} (\nabla\times u)_1 = \partial_{x_2} u_3 - \partial_{x_3} u_2, \\ (\nabla\times u)_2 = \partial_{x_3} u_1 - \partial_{x_1} u_3, \\ (\nabla\times u)_3 = \partial_{x_1} u_2 - \partial_{x_2} u_1. \end{gathered}\]

Use this in-place form when destination is already allocated; the allocating curl returns a fresh result instead. The arguments are:

  • destination — the vector field that receives the result; it shares the domain of field, and it may alias field freely: the fused pass reads all three source coefficients of a mode before writing any component of it, so the aliased call needs no guard temporary and is bitwise-identical to the non-aliased one.
  • field — the vector field to differentiate, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

The spectral symbol is a coefficientwise multiply by $\mathrm{i}$ times the cross product with the wavenumber vector, $\widehat{\nabla\times u}(k) = \mathrm{i} k \times \hat u(k)$, componentwise:

\[\begin{gathered} \widehat{(\nabla\times u)_1}(k) = \mathrm{i} (k_2 \hat u_3 - k_3 \hat u_2), \\ \widehat{(\nabla\times u)_2}(k) = \mathrm{i} (k_3 \hat u_1 - k_1 \hat u_3), \\ \widehat{(\nabla\times u)_3}(k) = \mathrm{i} (k_1 \hat u_2 - k_2 \hat u_1). \end{gathered}\]

symmetric_gradient!(

  field::VectorFieldSpectral,

Compute the symmetric gradient (symmetric_gradient $\equiv \operatorname{sym}\nabla$) of a vector field $u$ and write it into destination, returning destination. It is the symmetric part of the gradient $\nabla u$, the second-order tensor field

\[S_{ij} = \tfrac{1}{2} (\partial_{x_j} u_i + \partial_{x_i} u_j),\]

formed directly. It is the fused symmetric peer of curl, which extracts the antisymmetric part of $\nabla u$ as a vector: forming $S$ this way skips the full nine-component gradient tensor that sym(gradient(u)) builds only to symmetrize, so reach for it whenever the symmetric part is all you need.

Use this in-place form when destination is already allocated; the allocating symmetric_gradient returns a fresh result instead.

The arguments are:

  • destination — the second-order tensor field that receives the result; it shares the domain of field and holds one tensor order higher.
  • field — the vector field to differentiate, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

The spectral symbol symmetrizes $\mathrm{i} k_j \hat u_i$ in its two indices:

\[\widehat{S_{ij}}(k) = \tfrac{\mathrm{i}}{2} \bigl(k_j \hat u_i(k) + k_i \hat u_j(k)\bigr).\]

Second-order differential operators

GBGPeriodicFields.DifferentialOperators.laplacian! — Function
laplacian!(
  destination::AbstractFieldSpectral,
  field::AbstractFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

Compute the Laplacian (laplacian $\equiv \Delta$) of a field and write it into destination, returning destination. The Laplacian is a local operator: it sums the second partial derivatives of a scalar field $f$ over the three axes, and it acts on each component of a vector or tensor field alike, so it preserves the tensor order:

\[\Delta f = \partial^2_{x_i x_i} f, \qquad (\Delta u)_j = \partial^2_{x_i x_i} u_j.\]

Use this in-place form when destination is already allocated; the allocating laplacian returns a fresh result instead.

The arguments are:

  • destination — the field that receives the result; it matches the domain and tensor order of field.
  • field — the field to differentiate, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

The spectral symbol is a coefficientwise multiply by $-|k|^2$:

\[\widehat{\Delta f}(k) = -|k|^2 \hat f(k), \qquad |k|^2 = k_1^2 + k_2^2 + k_3^2.\]

GBGPeriodicFields.DifferentialOperators.inverse_laplacian! — Function
inverse_laplacian!(
  destination::AbstractFieldSpectral,
  field::AbstractFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

Compute the zero-mean inverse Laplacian (inverse_laplacian $\equiv \Delta^{-1}$) of a field $f$ and write it into destination, returning destination. For a mean-free right-hand side the result is the zero-mean field $\psi$ solving Poisson's equation — on a periodic box the system is solvable only when $\int_\Omega f\,\mathrm{d}x = 0$, since any periodic $\psi$ has $\int_\Omega \Delta\psi\,\mathrm{d}x = 0$ — and because the Laplacian annihilates constants, the solution is fixed uniquely by requiring its mean to vanish:

\[\Delta\psi = f, \qquad \int_\Omega f\,\mathrm{d}x = 0, \qquad \int_\Omega \psi \,\mathrm{d}x = 0.\]

A general input is projected onto that compatible part: the result's zero Fourier mode is set to zero unconditionally, so the operator returns the zero-mean solution of $\Delta\psi = f - \bar f$ ($\bar f$ the input's mean); the per-mode form below is the unconditional statement.

For a vector or tensor field the same solve is applied to each component, so the tensor order is preserved.

The inverse Laplacian is nonlocal

As the inverse of a differential operator, $\Delta^{-1}$ is nonlocal: unlike the Laplacian it has no local partial-derivative formula, and the value at any point depends on the whole field.

Use this in-place form when destination is already allocated; the allocating inverse_laplacian returns a fresh result instead.

The arguments are:

  • destination — the field that receives the result; it matches the domain and tensor order of field.
  • field — the field to invert, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

The spectral symbol divides by $-|k|^2$ away from the origin and sets the zero Fourier mode to zero:

\[\widehat{\Delta^{-1} f}(k) = \begin{cases} - \hat f(k) / |k|^2, & k \ne 0, \\ 0, & k = 0. \end{cases}\]

Projection operators

GBGPeriodicFields.DifferentialOperators.helmholtz_projection! — Function
helmholtz_projection!(
  destination::VectorFieldSpectral,
  field::VectorFieldSpectral,
  multipliers::FieldSpectralMultipliers,
)

helmholtz_projection!(destination, field, multipliers, kernel::SpectralKernel)
helmholtz_projection!(destination, field, multipliers,
                      kernel::SpectralKernel, α, β)

Compute the Helmholtz (Leray) projection (helmholtz_projection $\equiv \mathbb P$) of a vector field $u$ and write it into destination, returning destination. The projection removes the longitudinal (curl-free) part of the field and keeps the divergence-free part, subtracting the gradient of the pressure-like potential that solves the divergence:

\[\mathbb P u = u - \nabla \Delta^{-1}(\nabla\cdot u),\]

an identity exact on the resolved band (the inverse Laplacian keeps the true $k^2$ while the projector is built from the derivative family — the two coincide off the Nyquist planes). The implemented operator is the exact orthogonal projector onto the kernel of the discrete divergence: $\mathbb P^2 = \mathbb P$, and the divergence of the result vanishes, at every mode — the Nyquist planes included.

The projection is nonlocal in physical space

The inverse Laplacian $\Delta^{-1}$ is nonlocal, so $\mathbb P$ is a nonlocal operator in physical space even though it acts coefficientwise in spectral representation.

Use this in-place form when destination is already allocated; the allocating helmholtz_projection returns a fresh result instead. The arguments are:

  • destination — the vector field that receives the result; it shares the domain of field, and it may alias field at no cost: the projection is computed in a single pass that reads all three components of a mode before writing any of them, so the aliased call needs no temporary.
  • field — the vector field to project, in spectral representation.
  • multipliers — the wavenumber symbols for the field's grid.

The spectral symbol subtracts the longitudinal part $a_i (a\cdot\hat u)/|a|^2$ from $\hat u_i$, with $a$ the derivative wavenumber — the Nyquist-zeroed family the gradient and divergence use, equal to $k$ on the resolved band — and passes every mode with $a = 0$ unchanged (the zero mode, and the pure-Nyquist corners where the whole derivative wavenumber vanishes):

\[\widehat{(\mathbb P u)}_i(k) = \Bigl(\delta_{ij} - \frac{a_i a_j}{|a|^2}\Bigr) \hat u_j(k), \qquad \delta_{ij} \text{ the Kronecker delta}, \qquad a \ne 0.\]

The kernel-composed form

Passing a kernel composes the projection with a periodic convolution in the same fused pass. As a real physical object the result is the kernel-weighted local average of the projected field, $g \star (\mathbb P u)$ — a single operator, because convolution and projection both act coefficientwise in spectral representation, so the scalar symbol $\hat g$ multiplies the projection symbol. The additional arguments are:

  • kernel — the kernel's transfer function $\hat g$, in any storage class of a SpectralKernel — a StoredKernel holding one coefficient per mode, or a compressed class evaluated per mode (radial, separable, or their product), which costs $O(N)$ or a closure rather than $O(N^3)$, exactly as convolve! takes it (including its reality condition on $\hat g$); one scalar kernel weights all three components.
  • α, β — real accumulation weights as in convolve!: the four-argument form overwrites ($\alpha = 1$, $\beta = 0$), and the six-argument form computes

\[\widehat{\texttt{destination}}_i(k) = \alpha \hat g(k) \widehat{(\mathbb P u)}_i(k) + \beta \widehat{\texttt{destination}}_i(k).\]

The composed form replaces a helmholtz_projection! followed by a convolve! — one fused pass instead of two, saving a full read and a full write of destination per call.

Apply a coefficientwise contraction with the wavenumber vector, computing $\mathrm{i} (k_1 \hat s_1 + k_2 \hat s_2 + k_3 \hat s_3)$, where $k_a$ is the wavenumber component and $\hat s_a$ is the source field's spectral component along axis $a = 1, 2, 3$. The divergence operator uses this kernel for the vector-to-scalar case, and once per output component for the tensor-to-vector case.

The eleven-argument form composes the contraction with a coefficientwise kernel and the $\alpha$/$\beta$ accumulate in the same fused pass, computing $\texttt{dst} \mathrel{.=} \alpha \hat g \cdot \mathrm{i} (k_a \hat s_a) + \beta \texttt{dst}$ with $\hat g$ = kernel_data, branching on iszero(β) to overwrite or accumulate — the divergence analogue of _apply_convolution!.
