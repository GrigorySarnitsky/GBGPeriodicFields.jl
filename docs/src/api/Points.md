# Points

```@autodocs
Modules = [GBGPeriodicFields.Points]
Order   = [:module]
```

The `Points` module is the unstructured base of the package's fiber-bundle model: off-grid
positions and the field values there, as sections over a `PointSet` (the point-set counterpart of
the grid sections in [`Fields`](Fields.md)). It provides the data types and their full fiberwise
algebra; the grid↔point transfer kernels live in the [`Interpolation`](Interpolation.md) module.

- **Positions** — `Point` (a single coordinate triple, an alias of `FiberVector`) and `PointSet`
  (a structure-of-arrays collection of `M` positions, grid-free).
- **Point values** — `ScalarPointValues` / `VectorPointValues` / `TensorPointValues` under
  `AbstractPointValues`: field values sampled at the `M` points, mirroring the field tensor
  orders, representation-free. Their fiberwise algebra (M2 + M3, storage-wise broadcasting) is
  generated by reusing the FieldAlgebra builders.
